# DrawMapLight の完全比較と時間計測

```sh
python3 tests/client-native/run-draw-map-light.py

# ブラウザ版と同じ Wasm / -O2 でも実行できる（Node.js が必要）
source ~/emsdk/emsdk_env.sh
CXX=em++ CXXFLAGS=-O2 python3 tests/client-native/run-draw-map-light.py
```

ゲーム本体のビルドには追加しない独立した検証。生成ソース・実行ファイルは一時ディレクトリに置き、終了時に削除する。
SDK のキャッシュに書き込めない環境では、キャッシュを一時領域へコピーし `EM_CACHE` をその場所に設定する。

旧描画部分は `draw-map-light-old.inc` に保存し、新描画部分は実行のたびに本体の `SboCliDrawScreen.cpp` から、事前計算を含めて抽出する。
光源収集後の座標・半径・強度・暖色・マスク・視界・隠す範囲・歩行オフセットと背景を同じ条件で与え、描画範囲外とアルファを含む全出力バイトを `memcmp` で比較する。
ホストの既定コンパイルは `-O2 -ffp-contract=off`。Wasm と同様に積和を融合せず、fast-math は使用しない。

合計 2,845 ケース。固定シードのランダム入力 2,048 ケースに加え、画面内外の境界、光源 0/1/32 個、半径 0、マップ・キャラ最大半径、半径境界の前後の float、重なり、全光源位置での半径 0 の挿入、全方向・全歩行オフセットを検査する。
ランダム入力ではゲームと同じゆらぎの式を異なる時刻・マップ座標で使い、マスク有無・暖色・隠す範囲・視界の各状態と描画領域の切り詰めを混ぜる。

時間計測は 480×480 画素が見える画面で、分散した 32 光源（半径 96、マップ最大半径）と光源 0 個を使用する。
背景の復元も含め、ウォームアップ後に旧・新を交互の順番で各 60 フレーム×5 回実行し、1 フレームの時間の中央値を表示する。各計測入力も完全比較する。

除外条件は、ゆらぎ反映後の半径について `fDY * fDY >= afR[i] * afR[i]`。
非負の `fDX * fDX` を加えても距離二乗は小さくならないため、旧実装でも必ず `continue` する光源だけを除ける。
半径 0 は一覧に残し、一覧は元の光源順を維持する。積・和・補間・平方根・光の合成の式と演算順は変えず、不変な値の計算だけをループ外へ移している。
