# サーバー回帰テスト

性能改善の前後で、送信バイト列・キャラ状態・経路探索の結果が変わらないことを確かめる。

- 実行して golden と比べる: `tests/server/compare.sh`（「一致」と出れば OK。BENCH 行は計測値）
- 出力だけ見る: `tests/server/run.sh [出力ファイル]`
- golden を作り直す（挙動を意図して変えた時だけ）: `tests/server/run.sh /tmp/x.txt && grep -v -e '^BENCH' -e '^\[' /tmp/x.txt > tests/server/golden.txt`

現在の golden の実データは非公開リポジトリの `e50b862`（2026-11-07）。最新版のデータでは NPC 数・地形などが違うため、無関係な差分が出る。既存 golden を確かめる時は、この版を一時領域に展開して `SBO2003_PRIVATE_DIR` で指定する（非公開リポジトリの作業ファイルは変えない）。

```sh
mkdir -p /tmp/sbosvr-golden-fixture
git -C "$(tools/server/find-data.sh --repo)" archive e50b862 Release/SBODATA | tar -x -C /tmp/sbosvr-golden-fixture
SBO2003_PRIVATE_DIR=/tmp/sbosvr-golden-fixture bash tests/server/compare.sh
```
