# サーバー回帰テスト

性能改善の前後で、送信バイト列・キャラ状態・経路探索の結果が変わらないことを確かめる。

- 実行して golden と比べる: `tests/server/compare.sh`（「一致」と出れば OK。BENCH 行は計測値）
- 出力だけ見る: `tests/server/run.sh [出力ファイル]`
- golden を作り直す（挙動を意図して変えた時だけ）: `tests/server/run.sh /tmp/x.txt && grep -v -e '^BENCH' -e '^\[' /tmp/x.txt > tests/server/golden.txt`

中身（test_main.cpp）: A 送信(SendTo) / B 同画面内配信 / C myArray / D 経路探索(SEARCH2) / E キャラ巡回(TimerProc) / F 飛ぶ特技 / G すごろくの観戦参加 / H 他人に送るキャラ情報の項目消し（NPC番号 npcid も。0=送らない 1=正しい値） / I 町転送の行き先帳 / J 船で目覚めるベッドがばらける（マップ間移動のばらける範囲） / K 傭兵（道さがしの表が前の方法と同じか・敵探しの速さ・道具を持たせる取り引き・自分で回復・帰る時に返す） / L ついていく列のマップ間移動（ついていく側へのフェードの指示がアウト1回だけか） / N 道具欄・預かり所の並べ替え（入れ替え・種類順・50音順。装備が付いて動くか・取り引き中は動かないか・他人や短いパケットは弾くか・50音キー sortkey の同じ/違う） / P 預かり所の品を引き取らずに売る・捨てる（売値は価値/4・値打ちの無い品は売れない・捨てられない品はどちらもだめ・所持金 999999 を超える分は売らない・品や個数の違い・他人・短いパケットは弾く） / M ギルドの依頼（受ける→見えるNPCが持ち主と仲間にだけ届く（関係ない人には 1 つも送らない）・ぶつからない・宝箱で品物と旗と段・ポータルで移る・ギルドで渡して報酬と済みの印・別の依頼の人は仲間になれない・取り消し・依頼を受けた管理者は同じマスに重なったほかの人の光ではなく自分の光で移る・依頼データとキャラの進み具合を保存して読み直す） / O 押せるNPCを押す向き（サーバーに前の向きが残っていても、押した人のいる側から押した方へ動くか） / Q 討伐チャレンジ（一人では受けられない・パーティで受ける・入口で全員が貸し出しセットになり敵が出る・保存の間だけ本物に戻る・預かり所に入れられない・倒れた人だけ戻る・敵を倒すと成功の印で戻る・初回だけ報酬・同じ依頼は 1 組だけ・切断とパーティ離脱で戻る・新しい欄の保存） / S 道具を使った時のメッセージに入力待ちを足すか（説明文に @2 が無いと出てすぐ消える） / R 攻撃力・守備力アップ（最低でも上がる量・強い人は率・かけ直しで重ならない・時間切れで戻る・敵にはかからない・アイコン用の残り時間を送る数） / U 管理者ウィンドウからギルドの依頼を直す（一覧が 1 件ずつ届く・直すと番号は変わらない・マップの外や入口の置き場違い・範囲外の番号・名前なしは断って中身を変えない・足すと空いている番号が振られる・短いパケットは無視） / X 敵を全部倒すと開く扉（範囲の外・別の空間の敵は数えない・敵がいる間は扉コマンドとSキーで開かず残りの数を知らせる・傭兵も開けられない・最後の1体が消えるとすぐ開いて音とメッセージ・時間では閉まらない・敵がまた出ると閉まるが扉の上に人がいる間は待つ） / Y 管理者ウィンドウの蘇生ボタン（倒れた人がHP満タンで起き上がり、蘇生の特技と同じエフェクトが出るか・管理者でない人と短いパケットは弾くか・倒れていない人はHPだけ満タン） / K2 傭兵への特技（プレイヤーの回復・蘇生の特技が、選んで・周り・画面内のどれでも傭兵に効くか・倒れた傭兵が起き上がるか・攻撃の特技は傭兵に当たらないか。ゲームの乱数を使うので最後に流す）。
時刻と乱数は固定、通信は mock_net.js、実データは非公開リポジトリ SBO2003-private の Release/SBODATA のコピー（元は書き換えない。探し方は tools/server/find-data.sh）。
