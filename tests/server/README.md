# サーバー回帰テスト

性能改善の前後で、送信バイト列・キャラ状態・経路探索の結果が変わらないことを確かめる。

- 実行して golden と比べる: `tests/server/compare.sh`（「一致」と出れば OK。BENCH 行は計測値）
- 出力だけ見る: `tests/server/run.sh [出力ファイル]`
- golden を作り直す（挙動を意図して変えた時だけ）: `tests/server/run.sh /tmp/x.txt && grep -v -e '^BENCH' -e '^\[' /tmp/x.txt > tests/server/golden.txt`

中身（test_main.cpp）: A 送信(SendTo) / B 同画面内配信 / C myArray / D 経路探索(SEARCH2) / E キャラ巡回(TimerProc) / F 飛ぶ特技 / G すごろくの観戦参加 / H 他人に送るキャラ情報の項目消し（NPC番号 npcid も。0=送らない 1=正しい値） / I 町転送の行き先帳 / J 船で目覚めるベッドがばらける（マップ間移動のばらける範囲） / K 傭兵（道さがしの表が前の方法と同じか・敵探しの速さ・道具を持たせる取り引き・自分で回復・帰る時に返す） / L ついていく列のマップ間移動（ついていく側へのフェードの指示がアウト1回だけか） / M ギルドの依頼（受ける→見えるNPCが持ち主と仲間にだけ届く（関係ない人には 1 つも送らない）・ぶつからない・宝箱で品物と旗と段・ポータルで移る・ギルドで渡して報酬と済みの印・別の依頼の人は仲間になれない・取り消し・依頼データとキャラの進み具合を保存して読み直す）。
時刻と乱数は固定、通信は mock_net.js、実データは非公開リポジトリ SBO2003-private の Release/SBODATA のコピー（元は書き換えない。探し方は tools/server/find-data.sh）。
