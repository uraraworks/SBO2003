## 画面と操作

PC ではキーボード、スマホでは画面下の仮想パッドで遊びます。

| PC | スマホ（縦持ち） |
|---|---|
| ![PC の画面](images/pc-screen.png) | ![スマホの画面](images/sp-screen.png) |

- 右下の小さな窓は自分の名前・HP（赤）・Mana（青）です。
- PC では、右下の「メッセージログ」にシステムメッセージや会話が残ります。スマホではパッドの下に出ます。
- PC でゲーム画面の右に出る「吹き出しウィンドウ」は、チャットで使える吹き出しの番号表です（[チャット](#チャット) を見てください）。

### 基本の操作

| やりたいこと | PC | スマホ |
|---|---|---|
| 歩く・向きを変える | ↑ ↓ ← → | 左のスティック |
| コマンドを開く・決定・話を進める | X | 決定（○）ボタン |
| キャンセル・閉じる | Z | キャンセル（✕）ボタン |
| 正面を調べる | S | 調べる ボタン |
| 戦闘モードの ON / OFF | Ctrl | 戦闘 ボタン |
| 表示の切り替え | Tab | 表示 ボタン |
| チャットする | Enter | 💬 チャット ボタン |

- 歩く方向と違う向きのキーを押すと、最初の1回はその場で向きだけ変わります。もう一度押す（押し続ける）と歩きます。
- 斜めには歩けません。
- スマホのパッドはタッチできる端末だと自動で出ます。

### Z キーの使いみち

メニューを閉じる以外に、次の使いみちがあります。

- 正面にいる人の後ろに **ついて行く** / ついて行くのをやめる
- 戦闘の攻撃ゲージや、特技の詠唱を **やめる**

### 表示の切り替え（Tab）

押すたびに、キャラクターの名前と右下のステータス窓の表示が切り替わります（4通り）。
スクリーンショットを撮る時などにどうぞ。

## コマンド

X（スマホは決定ボタン）でコマンドを開きます。↑↓←→ で選んで X、Z で閉じます。

![コマンドメニュー](images/command-menu.png)

| コマンド | 内容 |
|---|---|
| 話す | 正面の人と話します。お店はカウンター越しに話しかけます |
| 特技 | 覚えている特技を使います |
| 強さ | ステータス・所持金・装備・属性を見ます |
| 道具 | 持っているアイテムを「使う」「捨てる」 |
| 装備 | 武器・防具を付け替えます |
| 調べる | 足元や正面を調べます（S キーと同じ） |
| 仲間 | 仲間（パーティー）を組みます |
| 取引 | 正面のプレイヤーとアイテム・お金を交換します |
| 扉 | 正面の扉を開けます |
| その他 | 自己紹介・名前の色・オプションなど |

### 強さ

![強さ](images/status.png)

職業・レベル・HP・Mana と、力・素早さ・体力・賢さ・運のよさなどの能力、火・水・風・土・光・闇の属性が見られます。
右上には所持金が出ます。

### 装備

左のリストで場所（武器・鎧・盾・兜・小手・靴・首飾り・指輪１・指輪２）を選ぶと、そこに付けられるアイテムが出ます。
選んでいる間、下に付け替えた後の攻撃力・守備力が出るので見比べられます。

![装備](images/equip.png)

### 道具

| 持ち物 | アイテムを選んだところ |
|---|---|
| ![道具](images/item.png) | ![使う・捨てる](images/item-select.png) |

- **使う**: 回復アイテムを使ったり、特技を覚えるアイテムを読んだりします。
- **捨てる**: アイテムを手放します。

アイテムはお店で買うほか、宝箱などを調べたり、人からもらったりして手に入ります。

### 仲間

- **仲間に誘う**: 近くのプレイヤーを仲間に誘います。
- **抜ける**: 仲間から抜けます。
- **分配方法**: 手に入れたものの分け方を決めます。
- **解散**: 仲間を解散します。

仲間になると、敵を倒した時の経験値がメンバーにも配られます。

### 取引

正面に立っているプレイヤーと、アイテムやお金をやり取りできます。お互いの取引画面で内容を決めて確定します。

### その他

![その他](images/etc-menu.png)

| 項目 | 内容 |
|---|---|
| ログ保存 | メッセージログを保存します |
| 自己紹介メッセージ確認 / 設定 | 他の人に見せる自己紹介文を見る・決める |
| 名前の色設定 | 頭の上に出る名前の色を変えます |
| パスワードの変更 | アカウントのパスワードを変えます |
| 管理人呼び出し | 困った時に管理人を呼びます（いない時もあります） |
| オプション | 下の表を見てください |

![オプション](images/option.png)

| オプション | 内容 |
|---|---|
| 発言徐々に消える ON/OFF | 吹き出しの発言を少しずつ消すかどうか |
| 音楽 ON/OFF | BGM を鳴らすかどうか |
| 吹き出し効果音 ON/OFF | 吹き出しを出した時の音 |
| 吹き出しウィンドウ ON/OFF | 吹き出しの番号表を出すかどうか |
| CPU活動具合切り替え | 処理の重さの切り替え |
| 音量(曲) / 音量(効果音) | 音の大きさ |
| 天候の描画 ON/OFF | 雨や雪などの表示 |
| タイトル画面のスキップ | 次からタイトル画面を飛ばします |

ブラウザ版では、ブラウザの決まりで最初に画面をクリック（タップ）するまで音が鳴りません。

## 町の施設

![始まりの町](images/town.png)

町には次のような施設があります。人や看板の正面に立って、話す（X → 話す）か調べる（S）を使います。

| 施設 | できること |
|---|---|
| 武器屋・防具屋・道具屋 | アイテムを買う・売る |
| 冒険者登録所 | 職業を変える |
| 教会（神父） | 話しかけると、気絶した時に戻ってくる場所が記録されます |
| 預かり所 | アイテムを預ける・引き取る |
| 宿屋 | 部屋で休めます |
| 着せ替え所 | キャラクターの姿を変えます |

### お店

店員とはカウンター越しに話します。「買いにきた」「売りにきた」を選び、品物を選ぶと右下にくわしい情報（種類・価値・攻撃力・装備できる職業）が出ます。

| 話しかけたところ | 品物を選ぶ |
|---|---|
| ![お店](images/shop.png) | ![品物の一覧](images/shop-buy.png) |

買ったものはすぐには装備されません。コマンドの「装備」から付けてください。

### 冒険者登録所（職業を変える）

始まりの町の北の建物にあります。右側の受付の人に話しかけて「職業の変更」を選びます。
左側の説明係は、着せ替え所の行き方を教えてくれます。

| 受付 | 職業を選ぶ |
|---|---|
| ![冒険者登録所](images/job.png) | ![職業の一覧](images/job-select.png) |

最初は **旅人** です。職業ごとの特徴は [[世界・データ図鑑]] の「職業」を見てください。

### 着せ替え所（姿を変える）

始まりの町の右下の階段を降りて、まっすぐ進んだ先にあります。
左の階段は人間・動物、右の階段はモンスターの姿です。なりたい姿のキャラクターに話しかけると、その姿に変われます。

## 戦闘

町の外のフィールドやダンジョンには敵がいます。町の中では戦えません。

![フィールド](images/field.png)

### 戦い方

1. 戦えるマップで **Ctrl（スマホは「戦闘」ボタン）** を押して戦闘モードにします。「戦闘モードに切り替えました。」と出ます。
2. **X** で戦闘コマンド（攻撃・特技・道具）を開きます。
3. **攻撃** を選び、↑↓ で相手を選んで X。
4. 頭の上の **ゲージ** がたまります。たまる速さは素早さで変わります（1〜3秒くらい）。
5. ゲージが満タンになった時、相手が **正面のとなり** にいれば自動で攻撃します。

| 戦闘コマンド | 相手を選ぶ | ゲージがたまる |
|---|---|---|
| ![戦闘コマンド](images/battle-command.png) | ![相手を選ぶ](images/battle-target.png) | ![ゲージ](images/battle-gauge.png) |

- 敵は動き回るので、となりに回り込んで、敵の方を向いてください。
- ゲージが半分以上たまっていれば、X で満タンを待たずに攻撃できます。そのぶん威力は下がります。
- Z でゲージをやめられます。
- 戦闘モードをやめる時は、もう一度 Ctrl を押します。

![敵を倒したところ](images/battle.png)

与えたダメージは相手の頭の上に数字で出ます。倒すと経験値とお金が手に入り、経験値がたまるとレベルが上がります。

### 特技

戦闘コマンドの「特技」（戦闘モードでない時はコマンドの「特技」）で使います。
特技は職業ごとに覚えられるものが違い、特技を覚えるアイテムを使って覚えます。
特技を選ぶと詠唱が始まり、Z で中断できます。

### 気絶したら

HP がなくなると気絶して、次のどちらかを選びます。

- **この場で助けを待つ**: 仲間に蘇生してもらうのを待ちます。
- **記録した場所で復活する**: 最後に教会の神父と話した場所に戻ります。

## チャット

PC は **Enter**、スマホは **💬 チャット** ボタンで入力欄が開きます。文字を入れて Enter（送信）で発言します。
発言はキャラクターの頭の上に吹き出しで出て、メッセージログにも残ります。

![チャット](images/chat.png)

### 特別な発言

| 入力 | 内容 |
|---|---|
| `#番号`（例: `#2`） | 吹き出しアイコンを出します。番号は「吹き出しウィンドウ」の表を見てください（1〜99） |
| `!発言` | マップ全体に聞こえるように話します（できるマップだけ） |
| `<発言` | 画面に映っている人に聞こえるように話します（できるマップだけ） |
| `/dice` | サイコロ（1〜6）。`/dice 3` のように数を付けると 3 個振ります（6 個まで） |
| `/2d6` `/3d6` `/1d10` `/1d20` | いろいろなサイコロ |
| `/coin` | コイン（表・裏） |
| `/keno` | 1〜80 の数 |
| `/now` | 今の時刻 |

![吹き出し](images/balloon.png)

## ちょっとした遊び

- 雪の上で S（調べる）を押すと雪をつかみ、もう一度押すと投げられます。
- 酔っぱらうと、歩く方向があべこべになったり、ふらついたりします。
- 爆弾ゲーム・戦場ゲーム・すごろく・雪合戦などのミニゲーム用のマップもあります。戦場ゲームのルールは [[戦場ゲーム]] にまとめています。
