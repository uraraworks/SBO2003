## 職業

最初はみんな **旅人** です。始まりの町の冒険者登録所で変えられます（[[遊び方ガイド]] の「冒険者登録所」）。
説明は、町にいる各職業の人のセリフから取っています。

| 職業 | 特徴 |
|---|---|
| 旅人 | 世界を股に掛ける自由業者。暗闇を照らす術や瞬時に移動する術を持っています。投げナイフや弓矢は旅人にしか扱えません |
| 戦士 | ほかの職業には装備できない重い武具を装備できます。得意な武器は斧・ハンマー・剣 |
| 武道家 | 肉弾戦が得意。得意な武器はナックルや爪などの専用武器。盾や重い防具は装備できません |
| 僧侶 | 回復魔法で自分やほかの人を回復できます。得意な武器は杖と槍。重い盾は装備できません |
| 魔法使い | 攻撃魔法が得意。得意な武器は杖。重い盾は装備できません |
| 商人 | 商いが得意な職業。いろいろな武器を使えますが、戦闘向きではないかも |
| 召喚士 | あとから追加された職業 |
| 吟遊詩人 | あとから追加された職業 |
