# ピンボールの台（段階1：ひとり用の台1つ）

縦長の定番ピンボール台を、ふつうのマップに置いた「台」で遊べるようにしたものです。
作りは落ち物パズル（`docs/falling-puzzle.md`）の台と同じ型（台NPC・席・コイン・待機中の台・近くの人への盤面送信）で、物理だけが違います。
段階1は「ひとり練習の台 1 つ」まで。記録（ランキング）・対戦・台のデータ化（管理画面での設定）は今回やらず、後から足せる作りにしてあります（末尾の「後で足す所」）。

## 遊び方

- 台の「座る場所」のマスに立って、コマンド→道具→コイン（その台のコインのアイテム）を「使う」と座って始まる。必要枚数は台詞で決める（足りなければ「コインがありません。」で座れず、コインは減らない）。コインが 0 枚の台は無料で、座る場所で S キーを押すと始まる。落ち物パズルの台と同じ扱い（座る場所以外では座れない・有料の台は S キーでは案内だけ・使用中の台には座れない）。落ち物パズルの席に座っている間はピンボールに座れず、その逆も同じ。
- 台NPCは見えない（体も名前も描かない）。盤は台NPCの真下（既定）の席の真上に出る。座る場所に立っている間だけ、その人の画面に「INSERT COIN」（無料の台は「PUSH START（Sキー）」）が点滅する。
- 座っている間はキャラが歩かない。操作は次のとおり。特技ショートカットなど他のキーは効かない。

| キー | 動き |
|---|---|
| ←（または Z） | 左フリッパー（押している間上がる） |
| →（または X） | 右フリッパー（押している間上がる） |
| ↓ | 押して離すと打ち出し。押している時間が強さ（`PB_CHARGE_MS`＝1 秒で最大。それ以上は上限）。溜めている間はレーンに強さの棒が伸びる |
| ESC | 席を立つ（途中で立つと得点は残らない） |

- スマホ：座っている間は、仮想パッドの十字キーの左右＝フリッパー、下＝打ち出しがそのまま効く（落ち物パズルと同じ仮想パッドの扱い。調べる(S)は隠れ、決定(X)・キャンセル(Z)のボタンは「右（フリッパー）」「左（フリッパー）」の表示になる）。
- 球は 3 球（`PB_BALLS`）。穴に落ちたら次の球が右端のレーンに来る。3 球目が落ちたらゲームオーバー（得点をシステムメッセージに出して席を立つ。最後の「GAME OVER」と得点は 3 秒ほど盤の上に残る）。切断・マップ移動・席から離れる（座る場所から 3 マス超）・倒れた時は台を片付ける。
- ボールセーブ：球を打ち出してから約 8 秒（`PB_SAVE_MS`）の間は、穴に落ちても同じ球をもう一度打ち出せる（1 球につき 1 回。帯に「SAVE n」の残り秒が出る）。
- 得点：バンパー（丸い反発）1 回 100・ターゲット 1 回 300。ターゲットは当てると倒れて通り抜けられるようになり、3 つ全部倒すとボーナス 1000 でターゲットが復活する。2 秒（`PB_COMBO_MS`）以内に続けて当てるとコンボ（帯に「COMBO n」。段階1では表示だけで加点はしない）。
- 帯（得点・残り球・コンボ・ボールセーブ）は座っている本人の台にだけ出る（`bySide`＝帯の側は台詞で決める）。ほかの人（観戦）には盤の上に小さく得点と残り球だけ出る。待機中の台（席が空）も近くを歩く人には枠・壁・バンパー・ターゲット・フリッパーだけ見える。

## 台の形（窓 160×224、盤全体は縦に長い）

- 盤を見る窓は 160×224 ピクセル（`PB_W`×`PB_VIEW_H`。落ち物の 10×14 ブロックと同じ 5×7 マスの場所取り。マップ上の場所取りはこの窓の大きさで、盤が高くても変わらない）。
- 盤全体の高さは `PB_H`（既定 448＝窓 2 画面分。`PB_VIEW_H` 以上なら何でもよい）。物理は盤全体で動き、窓がボールを追って上下に動く（下の「スクロール（カメラ）」）。`PB_H` と同じ（224）にするとスクロールのない 1 画面の台になる。
- 配置の決め方：フリッパー・穴・斜め壁・打ち出しレーンの床・下側のバンパー 3 個・ターゲット 3 個は盤の下端に寄せる（座標に `PB_YOFS`＝`PB_H-PB_VIEW_H` を足す）。上部のアーチは盤の最上部（`PB_ARCH_CY`）。盤が窓より十分高い時（`PB_UPPER`＝`PB_YOFS` が 120 以上）は、アーチの下にバンパー 3 個・ターゲット 3 個、中ほどにバンパー 2 個を足す（合計バンパー 8・ターゲット 6。ターゲット 6 つ全部倒すとボーナス）。縦（y）は盤の上端からのドット数そのまま、横（x）は 160 を `PB_W` に比例させる。
- 左右の壁・上部のアーチ（半円）・左右の下の斜め壁（フリッパー溝）・左右のフリッパー・中央下の穴・右端の打ち出しレーン（プランジャー。盤の上のアーチまで続く）・バンパー・ターゲット。絵は図形（円・線・矩形）だけ（`SboCliDrawScreen.cpp` の `DrawPinball`）。
- 打ち出しの強さ：盤が高いほどレーンが長いので、最大の強さは盤の高さから決まる（`PinballTable::nLaunchMax`＝レーンの床からアーチの縁まで届くのに要る速さの 1.3 倍。`PB_LAUNCH_REACH`＝17 は二乗の比で 1.7 倍）。レーンの中だけ速さの上限が高い（`PB_VMAX_LANE`。盤の中は `PB_VMAX` のまま）。

### スクロール（カメラ）

- 窓の縦位置（`nCamY`＝窓の上端が盤の上端から何ドット下か。0〜`PB_YOFS`）はクライアントだけで決める。サーバーは位置を送らず、通信の盤の状態（`CMDPARA_PINBALLSTATE`）も増えない。
- 本人は先読みしたボール位置、観戦者は補間したボール位置から、同じ式で決める（`SboCliPinball.cpp` の `CamUpdate`）：球を打ち出して飛んでいる間（`PB_PHASE_PLAY`）は、球が窓の縦の中央にくる位置を目標にし、盤の上下端で止める。待機中の台・打ち出し前（`PB_PHASE_READY`）・穴に落ちて返事待ち・ゲームオーバーは下端を映す。
- 目標へは急に飛ばず、時間で滑らかに寄る（毎回、残りの差の `dt/(dt+PINBALL_CAM_MS)` だけ進む。`PINBALL_CAM_MS`＝90）。新しい台・待機中の台は目標へ寄せずに直接置く。
- 描画：盤の絵（壁・アーチ・バンパー・ターゲット・フリッパー・ボール・溜めの棒）は窓の中だけに切り取る。帯（得点・残り球など）・文字・窓の左端の位置の目印（細い縦線。盤が窓より高く、遊んでいる時だけ）は窓に固定。
- 球が穴に落ちるのは、2 つのフリッパーの軸の間の縦穴だけ（軸の下に縦の壁があり、斜め壁の外へ回り込めない）。

## 台の作り方（台詞の印と引数）

コードは「台詞の先頭の印」で台を見分けます（`@p`＝落ち物パズル・`@d`＝ダンジョン受付などと同じ仕組み。`@i` は他で使っていない）。管理者ウィンドウで NPC を置き、台詞に次を書くだけです。

```
@i<コインのアイテム番号>,<必要な枚数>,<dx>,<dy>,<帯の側>,<sdx>,<sdy>
```

後ろは省略でき、空欄も既定になります。

| 項目 | 意味 | 既定 |
|---|---|---|
| コインのアイテム番号・必要な枚数 | 席に座る時に使う。どちらかが 0 なら無料 | 無料 |
| dx, dy | 盤の左上が、台NPCのマスの左上から何マスか（負は左・上） | 席が盤の真下（-2,-6。盤の一番下のマス行が台NPCのマスと重なる） |
| 帯の側 | 0=盤の右・1=盤の左 | 右 |
| sdx, sdy | 座る場所：台NPCのマスからの相対位置（マス。±60 まで）。このマスに立ってコインを使う（無料の台は S キー）と座る | 0,+1（台NPCの 1 つ下） |

例:

- `@i20,1` … アイテム 20 を 1 枚使う。盤は席の真上
- `@i` … 無料（S キーで始まる）
- `@i20,1,2,-3` … 盤の左上を席の右 2・上 3 マスにする（席の横に置く）
- `@i20,1,,,1` … 帯を盤の左に出す
- `@i20,1,,,,3,0` … 座る場所を台NPCの右 3 マスにする

台NPCは「移動しない」などふつうの NPC でよく、台詞が `@i` で始まっていれば台になる。台NPCは見えない（サーバーが `CMD_CHARINFO` の `byGhost` を `CHARGHOST_NAMEONLY` に上書きして送り、クライアントは台詞が `@i` のそのキャラの名前も描かない）。台の絵（壁や筐体の見た目）はマップのパーツで作る（盤の中は台が描く）。盤は画面の中央（自分のキャラ）から見て上下 7 マス・左右 7 マスの範囲に入る位置にする。コインのアイテムと配布係は落ち物パズルと同じ（`docs/falling-puzzle.md` の「コインと配布係」）。同じアイテムをコインにしてよい。

## 通信

| コマンド | 向き | 内容 |
|---|---|---|
| `CMD_PINBALLKEY` | クライアント→サーバー | `CMDPARA_PINBALLKEY`（`byData`＝`PINBALLKEY_*`、`dwSerial`＝連番）。**押した時と離した時だけ**送る。`LEFT_DOWN/UP`・`RIGHT_DOWN/UP`・`LAUNCH_DOWN/UP`（↓を押す/離す。押していた時間はサーバーが自分の時計で測る）・`LEAVE`（ESC） |
| `CMD_PINBALLSTATE` | サーバー→座っている人と台の近くの人 | `CMDPARA_PINBALLSTATE`（約 0.1 秒ごと＝`PINBALL_SEND_MS`と、得点・球・状態が変わった時）。ボール位置と速度（1/256 ドット）・フリッパーの段階・ターゲットの倒れた印・得点・残り球・コンボ・ボールセーブ残り秒・固定ステップ数 `dwStep`・処理したキーの連番 `dwAck`・当たった印 `wFlash`（バンパー・ターゲットを光らせる。ビット数は `PB_BUMPERS+PB_TARGETS`。16 まで） |

- `byKind`：`PINBALLSTATE_FULL`（状態）・`PINBALLSTATE_OVER`（ゲームオーバー。本人に）・`PINBALLSTATE_NONE`（見えなくなった・片付いた）。待機中の台は `byIdle`（`PINBALLIDLE_ON`/`SEAT`/`FREE`。落ち物パズルの `PUZZLEIDLE_*` と同じ意味）。`byOver=1` の間は「GAME OVER」と得点を盤の上に出す。
- 送り先：座っている本人と、台の近く（盤が画面にかかる距離）にいる人。距離の決め方・近づいた人へ 1 回送り離れた人へ `NONE` を送る見直し（`PINBALL_WATCH_MS`＝250ms）は落ち物パズルと同じ（サーバーは `PINBALL_VIEW_ENTER`、消すのは `PINBALL_VIEW_LEAVE`）。同じマップで遠い人には送らない。
- サーバーが正：得点・残り球・ターゲットはサーバーが決め、クライアントは決めない。キー入力に伴う即時の送信はバケツ（8 個・25ms に 1 個）で制限する（状態は周期処理でも送る）。
- 旧クライアントは新しいコマンドを知らないだけで、既存のコマンド番号・既存機能は変えていない（`CMD_MAX` の直前に 2 つ足した）。

### クライアントの先読みと補間（`SboCliPinball.cpp`）

- 本人の台：`common/Pinball.h` の `PinballGame` を手元で回す（先読み）。キーを押した瞬間にフリッパーを手元で動かす。サーバーの状態が届くたびに、その状態（`dwStep`・ボール・速度・フリッパー・ターゲット）から作り直し、`dwAck` より後の未処理のキーを時刻どおりにかけ直して今まで進める。ボール位置の飛びは「見た目のずれ」として持ち、1 ステップごとに 15/16 に縮めて少しずつ寄せる（24 ドット以上ずれたら飛ばす）。片道の時間（最短の往復÷2）を見積もり、状態が古い分だけ進める。穴に落ちた先読みは球を減らさず止まり、サーバーの返事を待つ（先読みの得点・残り球は使わない）。
- ほかの人（観戦者）：先読みしない。届いた位置を 150ms（`PINBALL_INTERP_MS`）遅らせて線形補間して描く（壁で跳ねた・飛んだ時は新しい方へ）。フリッパーは遅らせた時刻の段階。
- キー：座っている間は `KeyProc` の先頭で `PinballKeyPoll` がキーの状態（←→↓ESC・X・Z）を見て、変わった時だけ送る（方向キーのイベントは 1 回に 1 つしか残らず「離した」を取りこぼしてフリッパーが上がりっぱなしになるため、イベントでなく状態で見る）。

## 物理の構造（`common/Pinball.h`）

- 純粋なロジック（`string.h`・`stdlib.h` だけに依存。通信・時計を知らない）。サーバーとクライアントで同じコードを使う。**整数の固定小数点だけ**（浮動小数点なし）なので、同じ入力からは必ず同じ結果になる（決定的）。
- 単位：位置・長さは 1/256 ドット（`PB_FP`）、速度は 1 ステップあたりの 1/256 ドット。時間は固定ステップ **1/120 秒**（`PB_STEP_HZ`）。`PinballGame::Update(経過ミリ秒)` が端数を持ち越して固定ステップを回す（遅れすぎは `PB_MAX_CATCHUP` ステップまでで捨てる）。サーバーは `g_dwTime` の経過時間をそのまま渡す（`PinballProc`・`Advance`）。キーが届いた時は、まず経過時間ぶん進めてから反映する（入力の時刻が合う）。
- 三角関数：sin は 5 度刻み（0〜90 度）の整数表（`g_asPbSin90`。1.0＝1024）。フリッパーの角度は段階（0〜`PB_FLIP_STEPS`＝12。1 ステップで 1 段階＝約 0.1 秒で上がり切る。1 段階 `PB_FLIP_DEG`＝5 度、休み位置は水平から 30 度下、上がり切ると 30 度上）の表引き。平方根は整数（`PbIsqrt`）。
- 速さの上限：`PB_VMAX`（約 420 ドット/秒）。重力 `PB_GRAVITY`、各面の反発（`PB_E_*`、/256）、バンパーの最低の弾く速さ `PB_BUMPER_KICK` などは定数（遊びながら調整する）。
- 衝突：ボール（円）対 壁（線分）・アーチ（内側の円）・バンパー（円）・ターゲット（太さのある線分）・フリッパー（回る線分＋太さ）。フリッパーは動いている分（前の段階の同じ位置との差）を面の速度として反発するので、押した瞬間に球を強く打ち返せる。**すり抜け（トンネリング）対策**：1 ステップをさらに最大 8 個のサブステップに分け、1 回の移動が球の半径の半分以下になるようにして調べる。球の最大の動き（約 3.5 ドット）と、フリッパー先端の動き（約 2.4 ドット/ステップ）の合計が、球とフリッパーの半径の合計（7 ドット）より小さい。壁にめり込んだら面の外へ押し戻す。
- ゲーム進行（`PinballGame`）：`READY`（球が打ち出しレーンで待つ）→`PLAY`→穴に落ちたら次の球の `READY` か `OVER`。クライアント先読み用に `bPredict`（穴に落ちたら `WAIT` で止まる）。動かない球を救う処理（約 5 秒ほとんど動かないと軽く弾く）・弱い打ち出しでレーンへ戻った球をまた打てるようにする処理もここ。
- 出来事（`PB_EV_*` のビット）を `Step`・`Update` が返す。サーバーはそれを見てシステムメッセージ（球が落ちた・ボールセーブ・ボーナス）や即時の送信を決める。
- 台詞の読み方（`PinballParseSpeech`・`PinballSeatOffset`・`PinballDefaultDx/Dy`・`PinballFieldPos`）も同じヘッダー（サーバーとクライアントで共通）。

## 作り（開発向け）

- 盤の高さを変えて試す：`g++ -std=c++11 -O1 -I. -DPB_H=336 tests/server/pinball_test.cpp -o /tmp/pbt && /tmp/pbt`（`PB_H` は 224 以上。224 ならスクロールのない 1 画面）。
- ロジック単体テスト `tests/server/pinball_test.cpp`:
  `g++ -std=c++11 -O1 -I. tests/server/pinball_test.cpp -o /tmp/pinball_test && /tmp/pinball_test`
  （決定的・壁や斜め壁を越えない・最大の速さで撃っても出ない・穴に落ちる・フリッパーで打ち返せる・ボールセーブ・3 球で終了・得点とボーナスとコンボ・台詞の読み方）。
- サーバー：`SboSvr/src/SboSvrPinball.cpp`（`SboSvrPinball.h`）。台は `PINBALLTABLE`（台NPC 1 つにつき席 1 つ）。道具のコイン（`ItemProc` → `PinballUseItem` → `PinballSit`）・S キー（`RecvDataProcTALKRAND` → `PinballSit`）・キー入力（`CMD_PINBALLKEY` → `PinballKey`）・周期処理（`SboSvr.cpp` の `PinballProc`。落ち物の `PuzzleProc` の直後）・切断（`OnDecPlayer` → `PinballOnLeave`）・座っている間の歩行止め（`PinballIsSeated`）・台NPCを見えなくする（`PuzzleGhostForSend` が `@i` も `CHARGHOST_NAMEONLY` にする）。
- クライアント：`SboCliPinball.cpp`（受信・先読み・補間・キー）・`SboCliDrawScreen.cpp`（`DrawPinball`。盤本体はキャラの前・帯と文字はウィンドウの下。落ち物と同じ 2 層）・`SboCliKeyProc.cpp`（`KeyProc` の先頭で `PinballKeyPoll`・座る場所の S キー・仮想パッドの `PADSTATE_PINBALL`）・`SboCliRecvCmd.cpp`（`IsPuzzleSeated` がピンボールの席も真にするので、歩行止め・ショートカット止め・仮想パッドの扱いは落ち物と同じ）。Web 版のビルド対象は `tools/web/sources.txt`、サーバーは `tools/server/sources.txt`。
- 絵の色・太さ・光る長さ（`PINBALL_FLASH_MS`）・補間の遅れ・見えるまでの距離は、それぞれ `SboCliDrawScreen.cpp`・`SboCliPinball.cpp`・`SboSvrPinball.cpp` の先頭の定数。

## 後で足す所

- 記録（ランキング）：得点が決まるのはサーバーの `Leave`（ゲームオーバー）の 1 か所。落ち物の `PuzzleRecordScore` と同じ作りの記録をここで足す。
- 対戦：台を 2 台ペアにして、片方の得点やコンボで相手へお邪魔（例：相手の球の追加・ターゲット復活）を送る形。`PINBALLTABLE` に落ち物の `bVs`・`dwOppNpc` に当たるものを足す。
- 台のデータ化：球数・重力・バンパーやターゲットの配置を台詞や管理画面で決める。今は `PinballTable`（`Pinball.h`）の定数。台ごとに変えるなら、`PinballTable` を台の設定から作り、通信の `byTargets`（8 まで）・`wFlash`（16 まで）のビット数を広げる。
- 効果音（バンパー・フリッパー・壁）：落ち物の `CMD_PUZZLESE` と同じ作りで足せる（今は音なし）。
