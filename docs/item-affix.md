# 付与（接頭辞・接尾辞）

ディアブロのように、装備に「鋭い」「の加護」などの付与が付き、強さと売値が変わります（第 1 段階）。
敵が落とす装備は最初「未鑑定」で、鑑定屋にお金を払うと付与が分かって効くようになります。

## アイテムの番号

アイテムの番号は WORD のままです（保存・通信の形は変わりません）。

- 0〜16383：今までの普通のアイテム（`g_aItemInfo` の添字）。
- 16384 以降：派生表（`SboDataItemDerive.dat`）の行番号 + 16384。1 行は `{wBase 元のアイテム, wPre 前の付与, wSuf 後ろの付与, byUnknown 未鑑定か}`。
  同じ組は同じ番号になり、サーバーが探して無ければ作ります（`AffixDeriveFindOrCreate`）。作った行は保存し、ログイン中の全員へ送ります。

`g_aItemInfo[番号]` は派生番号でも元のアイテムの情報を返します（`common/ItemAffix.h` の `CItemInfoArray`）。
範囲の確かめは `GetSize()` ではなく `ItemIDValid()` を使います。
表示・メッセージの名前は `ItemNameOf()`、強さは `ItemValueOf()`、魔法防御の付与は `ItemAffixDFMagic()`、売値は `ItemGoldOf()` を通します。

## 付与表（`SboDataAffixInfo.dat`）

| 項目 | 内容 |
| --- | --- |
| `wID` | 通し番号（1〜。0 は「付与なし」。管理ページで足すと自動で振られる） |
| `byPos` | 0=名前の前（鋭い） 1=名前の後ろ（の加護） |
| `szName` | 名前 |
| `wEquMask` | 付く装備種別のビット（武器・鎧・盾・兜・小手・靴・首飾り・指輪） |
| `chRate` | 主の値（武器は攻撃力・防具は守備力）に足す割合（%。マイナス可） |
| `chAdd` | 主の値に足す固定値 |
| `chDFMagic` | 魔法防御に足す値（プレイヤーが装備した時だけ） |
| `byRank` | ランク 1〜3（敵のランク以下のものだけ落ちる） |
| `wWeight` | くじ引きの重み |
| `wGoldRate` | 売値の割合（100=変わらない） |
| `byBad` | 1=悪い付与（詳細ウィンドウで赤く出す） |

最終値 = `byData + byData * 前後のchRateの合計 / 100 + 前後のchAddの合計` を 0〜255 に収めます。売値 = 元の値段 × 前後の `wGoldRate`/100。
**未鑑定の装備は装備できますが、強さも売値も付与の効果が無し**（元のアイテムのまま）です。

## ドロップ

ステータステンプレート（`stTmp`）に `byAffixRate`（付与が付く確率 %。古いデータは 10）と `byAffixRank`（敵のランク。古いデータは 1）があります。
重要アイテム以外の装備が落ちる時、まず `byAffixRate` で当たり判定をし、当たったら前・後ろをそれぞれ 70% で選びます（どちらも外れたらどちらか 1 つ）。
候補は装備種別が合い `byRank` が敵のランク以下のもので、重み付きで選びます。結果は**未鑑定**の派生番号で落ちます。
付与表が空の間は何も起こらず、乱数も使いません。

## 鑑定屋

作り手（`maker`）の種類（`byKind`）を「鑑定」にし、NPC の台詞を `@c` + 作り手の番号 2 桁にします（レシピの作り手と同じ仕組み）。
話しかけると、持ち物の未鑑定の装備が一覧に出ます。選んで「はい」を押すと、代金 `max(10, 元の値段/10)` ゴールドを払って鑑定済みの番号に置き換わります
（装備中ならそのまま装備して強さが変わり、ショートカットに登録していた物も付け替わります）。作り手の台詞 `szMsgDone` が鑑定後の台詞になります。

## 材料・宝箱・取引所など

レシピの材料は今まで通り番号の完全一致です（鑑定済みでも未鑑定でも別の物）。宝箱・取引所・取引は派生番号をそのまま通します。

## 通信

- `CMD_AFFIXINFO`・`CMD_ITEMDERIVE`（サーバー→クライアント）：ログイン時に付与表・派生表を全部送る。派生表は新しい行ができた時も全員へ送る。
- `CMD_APPRAISE`：クライアント→サーバーは `{byMaker, byNo}`、返事は `byResult`（0=できた 1=お金が足りない 2=できない）と払った額。

## データ API・管理ページ

- 管理ページ（`/admin`）の「付与」タブで付与表を足す・直す・消す。
- データ API：`affix`（読み書き。`wID` は自動）、`itemDerive`（読むだけ）、`stTmp` の `byAffixRate`・`byAffixRank`、`maker` の `byKind`（0=レシピ 1=鑑定）。

## 第 1 段階でやらないこと

付与の追加の条件（レベル・職業）、付与だけの付け替え、材料への付与の引き継ぎ、取引所の付与での絞り込みなど。
