# 落ち物パズルの台（段階1：ひとり用）

テトリス型の落ち物パズルを、ふつうのマップに置いた「台」で遊べるようにしたものです。
対戦（2 人目の割り込み）・観戦・お邪魔ブロックは段階 2 以降（`docs/` の仕様は `_work/sbo2003-falling-puzzle/仕様.md`）。

## 遊び方

- 台の席（台 NPC の目の前）で S キーを押すと座る。台に必要な枚数の専用コインを使って始まる（足りなければ「コインがありません。」で座れない。0 枚の台は無料）。
- 座っている間はキャラが歩かない。左右＝移動、下＝1 段落とす、S＝回す、ESC（スマホは「席を立つ」＝Z）＝席を立つ。特技ショートカットなど他のキーは効かない。
- 置けなくなったらゲームオーバー（得点をシステムメッセージに出して席を立つ。最後の盤面は 3 秒ほど画面に残る）。切断・席から離れる・マップ移動・倒れた時は台の状態を片付ける。
- 落下は 1 秒に 1 段、10 ライン消すごとに 80ms ずつ速くなる（下限 100ms）。得点は 1 列 100 / 2 列 300 / 3 列 500 / 4 列 800 とソフトドロップ 1 段 1 点。

## 台の作り方（データ投入）

コードは「台詞の先頭の印」で台を見分けます（`@d`＝ダンジョン受付・`@m`＝傭兵などと同じ仕組み）。管理者ウィンドウで NPC を置き、台詞に次を書くだけです。

```
@p<コインのアイテム番号>,<必要な枚数>,<dx>,<dy>,<横の段数>,<縦の段数>,<帯の側>
```

後ろは省略でき、空欄も既定になります。

| 項目 | 意味 | 既定 |
|---|---|---|
| コインのアイテム番号・必要な枚数 | 席に座る時に使う。どちらかが 0 なら無料 | 無料 |
| dx, dy | フィールドの左上が、台 NPC のマスの左上から何マスか（負は左・上） | 席がフィールドの真下（10×14 なら -2,-7）。横はフィールドの中央が席の中央、一番下の行が席の 1 マス上 |
| 横・縦の段数 | 盤面の大きさ（4〜16 × 4〜24） | 10×14（`PUZZLE_COLS`・`PUZZLE_ROWS`） |
| 帯の側 | 次の落ち物・得点の帯をフィールドの右(0)・左(1)のどちらに出すか | 右 |

例:

- `@p20,1` … アイテム 20 を 1 枚使う。フィールドは席の真上（10×14）
- `@p20,1,,,10,18` … 10×18 にする（位置は席の真上のまま決まる）
- `@p20,1,2,-3` … フィールドの左上を席の右 2・上 3 マスにする（席の横に置く）
- `@p` … 無料

NPC は「移動しない」などふつうの NPC でよく、台詞が `@p` で始まっていれば台になります（見た目の絵は自由。台の絵はマップのパーツで作る）。
キャラが座る位置は台 NPC の前後左右のマス（NPC からの距離 3 マス以内）。フィールドは地図 1 マス＝32 ドットに対し、ブロック 1 つ 16 ドット（盤面 10×14 は地図 5×7 マス）。
フィールドの絵は画面の中央（自分のキャラ）から見て上下 7 マス・左右 7 マスの範囲に入る位置にしてください。

## コインと配布係（爆弾ゲームの参加チケットと同じ作り）

- **コイン**: 管理者ウィンドウの「アイテム」で、効果なし（`ITEMTYPE_NONE`）の普通のアイテムを 1 つ作る（名前は「落ち物コイン」など）。使うと消える（台がサーバー側で 1 枚ずつ取り上げる）。台詞の「コインのアイテム番号」にこの番号を書く。
- **配布係**: 会話データ（`@tNNN`）の NPC を置き、会話セットの行の「話した後に渡すアイテム」に上のコインを入れる（`wGiveItem`。毎回渡すので何度でももらえる。一度きりにしたい時は印の条件で組む。持ち物がいっぱいなら預かり所へ入る）。
- 枚数の上限や毎回もらえるかは、会話データの設定（印・数値）で決まり、爆弾ゲームのチケットの配布係と同じ決まりにそろえられる。

## 作り（開発向け）

- 盤面ロジック（回転・衝突・ライン消し・得点・落下の速さ）は `common/FallingPuzzle.h`（通信・時計を知らない。調整用の定数もここ）。単体テスト `tests/server/falling_puzzle_test.cpp`:
  `g++ -std=c++11 -O1 -I. tests/server/falling_puzzle_test.cpp -o /tmp/fpt && /tmp/fpt`
- サーバー: `SboSvr/src/SboSvrPuzzle.cpp`。台は `PUZZLETABLE`（席は配列 `aSeat[PUZZLE_SEATS=2]`。段階 1 は席 0 だけ使う＝`PUZZLE_SEATS_USED`）。
  - S キー（`CMD_TALKRAND`）→ `PuzzleSit`。キー入力（`CMD_PUZZLEKEY`）→ `PuzzleKey`。周期処理は `PuzzleProc`（`SboSvr.cpp` の `g_ProcSubGame.Proc()` の直後。`g_dwTime` の経過時間で落下を進める）。
  - サブゲームの `SUBGAMEID_*`・`CProcSubGame` は使わない（台ごとの状態は台 NPC に結び付いていて、保存データも要らないため）。座っている間の歩行は `RecvDataProcCHARPOS` で止める。切断は `OnDecPlayer` → `PuzzleOnLeave`。
  - 座っている人にだけ、変わった時に `CMD_PUZZLESTATE`（盤面が変わった時は `PUZZLESTATE_FULL`＝盤面全体、動いただけは `PUZZLESTATE_MOVE`＝位置だけ）を送る。
- クライアント: `SboCliRecvCmd.cpp`（受信・`IsPuzzleSeated`・`GetPuzzleState`）、`SboCliKeyProc.cpp`（`KeyProcDispatch` の先頭で座っている間のキーをすべて `CMD_PUZZLEKEY` へ。押し続けの繰り返し間隔もここ）、`SboCliDrawScreen.cpp`（`DrawPuzzle`。マップの上・ウィンドウの下に重ね描き）。スマホの仮想パッドは `SboWebGetPadState` の 128（`PADSTATE_PUZZLE`）で「調べる」を「回す」、「キャンセル」を「席を立つ」にし、表示・戦闘・地図を隠す。
- ブロックの絵は新しい画像を作らず、種類ごとの単色＋縁の塗り分け（`PuzzleDrawBlock`）。
- サーバー回帰テスト `tests/server/test_main.cpp` の AV（コイン・席・キー・落下・ゲームオーバー・片付け）。
