# 取引所（商人ギルドの出張所）

プレイヤーが品を受付に預けてゴールドで売る「委託販売」です。
相手と時間を合わせなくても、オフラインのまま売り買いが成り立ちます。

## 決まりごと（2026-11-16 決定）

| 項目 | 内容 |
| --- | --- |
| 受付 | 始まりの町の預かり所のところ。NPC の台詞を `@b` にすると受付になる |
| 手数料 | 売れた時に値段の 5%（切り捨て）。出品者の手取りは 値段 − 手数料 |
| 値段 | 上限なし（所持金の上限 999999 まで）。下限は品の元の売値（価値の 1/4、最低 1） |
| 出品数 | 1 アカウント 5 件まで（期限切れで引き取っていない品も数える） |
| 期限 | 7 日。過ぎると「期限切れ」になり、買えなくなる |
| 売れ残り | 自動では戻さない。出品者が受付で引き取る |
| 売上 | 受付に貯まり、同じアカウントのどのキャラでも受付で受け取れる |
| 出せない品 | 装備中の品・取引不可の印（ITEMFLG_TRADE）の品・依頼の品 |
| 自分の品 | 同じアカウントの出品は「買う」一覧に出さない・買えない |

1 件 = 品 1 個（手持ちは 1 枠 1 個なので）。

## 受付のメニュー

`@b` の NPC に話しかけると次のメニューが出ます。

1. **買う**：出品中の品の一覧（品名・値段・出品者）。選ぶと「○○を△△ゴールドで買いますか？」→ はい で購入。
2. **出品する**：手持ちから品を選ぶ → 値段を入れる → 「手数料□□、手取り◇◇です。出品しますか？」→ はい。
3. **自分の出品**：自分のアカウントの出品の一覧（出品中・残り日数／期限切れ）。選ぶと「引き取る」で手持ちに戻す（出品中でも取り下げられる）。
4. **売上を受け取る**：貯まっている売上を所持金へ。999999 を超える分は受付に残す。
5. **やめる**

## 保存

サーバーの `SBODATA/SboDataMarket.dat`（依頼データと同じ列名つきの形式）。

- 出品：出品ID・アカウントID・キャラID・出品者名・品の種類ID・値段・出品した時刻・状態（出品中／期限切れ）
- 売上：アカウントID・貯まっている金額

売れた出品はその場で消し、手取りを売上に足します。
