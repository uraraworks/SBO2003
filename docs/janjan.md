# SBOじゃん（段階1：人間1人＋CPU3人）

ドンジャラ風の絵合わせを、ふつうのマップに置いた「卓」で遊べるようにしたものです。段階 1 は、座った人ひとりと CPU 3 人の 4 人で 1 局だけ遊びます。
サーバー側と通信定義が対象です（画面・操作はクライアント側の担当）。盤面ロジックは `common/Janjan.h`（通信・時計を知らない純ロジック。単体テストは `tests/server/janjan_test.cpp`）。

## 遊び方

- 卓は 7×7 マスで、4 辺に席があります。席に座る場所のマスに立って、無料の台は S キー、チケットの台は道具のチケットを使うと座れます（チケットは「始めますか？」の確認で「はい」を選んだあとに取り上げます）。どの席かは、立っているマスで決まります。
- 座ると歩けなくなり、1.5 秒後に配牌が始まります。座った席以外の 3 席は CPU（席名は「CPU1」〜「CPU3」）。親は席 0 です。
- 牌は 16 種類の絵が 4 枚ずつ（64 枚）。手牌は 8 枚で、引いたあとは 9 枚から 1 枚捨てます。3 枚ずつの組に全部分けられたら上がりです。
  - そろい：同じ絵 3 枚。組そろい：同じ組（絵の番号 ÷ 4 が同じ）の違う絵 3 枚。
  - 自分の番に引いて上がれる＝ツモ。他の人の捨て牌で上がれる＝ロン。
  - 捨て牌をもらって組を公開する「鳴き」ができます。そろい＝誰の捨て牌でも（同じ絵を 2 枚持っていれば）。組そろい＝すぐ左隣の席（次の番の席）の捨て牌だけ。鳴きは 2 回まで。
  - 申し出の強さは ロン ＞ そろい ＞ 組そろい。同じ強さなら捨てた人の次の席から先。
  - 山が尽きたら流局。上がると上がった人に 1 点（役は後で足す）。
- CPU は 700ms ごとに 1 動作（引く・捨てる・鳴きの確定）。人間の手番は 20 秒（時間切れは引いた牌を捨てる）。ロン・そろい・組そろいができる時だけ 8 秒待ち、時間切れは見送りです。
- 局が終わると「○○の上がり！」または「流局」がシステムメッセージで出て（○○は卓の席名）、全員の手牌が表になり、6 秒後に席が空きます。
- 卓が使われている間、ほかの人は座れません（「この台は今、使われています。」）。卓の近くにいる人は観戦でき、座っていない観戦者には全員の手牌が見えます。座っている人には自分の手牌だけが見えます。
- 席を立つ（ESC）・切断・マップ移動・座る場所から 3 マス超離れる・倒れる・台が無くなる、のどれかで卓は片付いて空卓に戻ります。
- 空卓は近くの人に枠が見えます。座る場所のマスに立っている人にだけ「座れます」の案内（INSERT COIN／無料なら PUSH START）の合図が付きます。

## 台の作り方（データ投入）

台の設定は「サブゲーム情報」（種別 8＝SBOじゃん。`SUBGAMEID_JANJAN`）に持たせます。迷路対戦・ピンボールの台と同じ方式です。
管理者ウィンドウの「サブゲーム編集」（種別を「SBOじゃん」にして、チケットのアイテム・枚数・CPU 強さを入れる）か、データ API（`subGame` の `byType` 8。`docs/ai-data.md` の「SBOじゃん」）で足して、その番号（サブゲームの `id`）を台NPCの台詞にします（コードの変更は要りません）。

    @j<サブゲーム番号>

- 例  サブゲーム番号 3 のサブゲーム情報が SBOじゃん なら、台NPCの台詞は `@j3`。
- サブゲーム情報の項目
  - `wTicketItemID`・`byTicketNum`：座る時に使うチケットのアイテム番号と枚数（枚数 0〜99。0 なら無料で S キー）。
  - `byCpuLevel`：CPU の強さ。1＝ランダム・2＝孤立牌から捨てる（既定）・3＝待ちを保つ捨て方も考える。0 は 2 として扱う。
- 番号の指すサブゲーム情報が無い・種別が SBOじゃん でない時は、無料・CPU 強さ 2 の台になります（`@j` だけの台詞も同じ）。
- 設定は次に座る時から効きます（遊んでいる最中の卓は、そのゲームの間は変わりません）。
- 旧形式 `@j<コイン番号>,<枚数>,<CPUの強さ>`（例 `@j314,1,3`）も、移行のため当面は読みます。台詞が数字だけ（カンマなし）なら番号、カンマがあれば旧形式です。旧形式の数字 1 つだけ（`@j314`）は枚数 0＝無料の意味で実質使われていなかったので、番号として読みます。
  新しく作る台は、サブゲーム情報の形にしてください。
- 台NPCのマスが卓の中心 (cx,cy)。盤は cx-3〜cx+3, cy-3〜cy+3。
- 座る場所のマス：席 0＝(cx, cy+4)、席 1＝(cx+4, cy)、席 2＝(cx, cy-4)、席 3＝(cx-4, cy)。台のまわりの 4 マスが空いている（歩ける）ようにしてください。
- チケット（枚数 1 以上）の台の座り方：座る場所のマスに立って、コマンド→道具→そのチケットを使う → 「チケットを N 枚使って始めますか？」（はい／いいえ）→ 「はい」でチケットを取り上げて座る。
  - 「いいえ」・30 秒たった「はい」は無効（座らず、チケットも減らない）。
  - 座る場所のマス以外で使っても効果なし。台が使用中・チケットが足りない時は確認を出さず、減らさない（案内だけ）。
  - チケットの台は S キーでは座れず、チケットを使う案内が出るだけです。無料の台は S キーで座ります。
- 台NPCは見えません（体も名前も描かない。`CMD_CHARINFO` に載せる `byGhost` を送る時だけ `CHARGHOST_NAMEONLY` にする。落ち物の `@p` と同じ関数）。

## 作り（開発向け）

- 通信（`common/TypedefCommon.h` の末尾、`CMD_MAX` 直前）
  - `CMD_JANSTATE`（S→C）`CMDPARA_JANSTATE`（pack 1・固定長 385 バイト）。卓の状態を受取人ごとに作って、変わった時だけ送る（同じ内容は再送しない。待ち残り `dwLimitMs` の違いだけでは送らない）。毎回全体の上書き。
    - `byKind`：`JANSTATE_NONE`（消す。席を立った・片付いた・卓から離れた）／`JANSTATE_STATE`。`dwNpc` で卓を見分ける。
    - `byMySeat`：受取人が座っている席 0〜3。座っていない人（観戦・空卓）は 0xFF。空卓で座る場所に立っていても 0xFF（どの席の案内かは自分の立っているマスと `JanjanSeatOffset` で決める）。
    - `byIdle`：`JANIDLE_ON`（空卓）・`JANIDLE_SEAT`（受取人が座る場所に立っている。空卓の時だけ）・`JANIDLE_FREE`（無料。SEAT と一緒）。
    - `byPhase`：`JANPHASE_IDLE`（空卓）／`JANPHASE_PLAY`（座ってから配牌までの 1.5 秒も含む。その間は手牌が空）／`JANPHASE_OVER`（終局表示）。
    - `byTurn`・`byLogicPhase`（`JANJAN_PHASE_*`）・`byPileLeft`・`byResult`・`byWinner`・`byWinHow`・`byLastSeat`。
    - `byLastTile`：鳴き・ロンの対象になっている直前の捨て牌（なければ 0xFF）。ロンで終わった時は上がり牌。
    - `byCanAct`（`JAN_CAN_*`）：受取人本人の今できる操作。ツモ＝自分の捨てる番で上がれる。ロン／そろい／組そろい／見送り＝人間の申し出の待ち（8 秒）の間。`dwLimitMs` は本人の待ち残り（送った時点の値。クライアントが減らす）。
    - `byGumiNum`・`abyGumi[3][2]`：組そろいで手牌から出す 2 枚の選び方（`CMD_JANKEY` の `byParam` はこの添字）。
    - `nFieldX`・`nFieldY`：卓の左上（7×7 マスの左上）のドット座標。
    - `aSeat[4]`（`JANSEATWIRE`）：`byState`（0 空・1 人間・2 CPU）・`szName`（UTF-8）・`sScore`・手牌（`abyHand[9]`。裏は 0xFF。**引いた牌は最後**。ツモ上がりの時も最後）・鳴いた組（`aMeld[2]`）・捨て牌（`abyRiver[32]`）。
    - 手牌の出し分け：座っている人は自分の席だけ表、観戦者は全員表、局が終わった時（`JANPHASE_OVER`）は全員表。
  - `CMD_JANKEY`（C→S）`CMDPARA_JANKEY`：`dwTblID`＝本人のキャラのテーブルID、`byAct`（`JAN_ACT_*`）、`byParam`（DISCARD＝牌id、GUMI＝`abyGumi` の添字）。反則・手番外・座っていない人のものは黙って捨てる（サーバーが正解）。LEAVE はいつでも効く。
  - 新しい CMD なので旧クライアントは黙って捨てる（旧クライアントには卓が見えない）。`SboSvrRecvCmd.cpp` の管理者ガードの除外リスト 2 か所に `CMD_JANKEY` を足してある。
- サーバー（`SboSvr/src/SboSvrJan.cpp`・`.h`）：`SboSvrPuzzle.cpp` と同じ作り。卓（`JANTABLE`）は表に載せ、座っている人・近くの人（`aWatch`）へ送る。`JanSit`（S キー・チケットの「はい」のあと）・`JanUseItem`（チケットを使った時の確認）・`JanAnswer`（確認への答え。`CMD_TALKANSWER`。30 秒で無効）・`JanKey`・`JanProc`（`SboSvr.cpp` のメインループ）・`JanOnLeave`（切断）。見直し・距離（送り始め 15 マス・消す 18 マス）は落ち物と同じ流儀。
  - 進行は `JanProc` が `g_dwTime` の経過時間で 1 回に 1 動作だけ進める（引く→捨てる→申し出の確定→次の席）。
  - 乱数の種は時刻と本人の番号から（テストは `g_dwJanSeedOverride` で固定）。
  - 人間のロンは、CPU の申し出と一緒に `JanjanResolveClaim` で優先を決める。人間が見送ったロンは後ろの席の CPU のロンを止めない。
- 席の位置と台詞の読み取り（`JanjanSpeechInfoNo`・旧形式の `JanjanParseSpeech`・サブゲーム情報の既定値と丸め `JanjanInfoSetDefault`・`JanjanInfoClamp`・`JanjanSeatOffset`）は `common/Janjan.h` にあり、クライアントも共用できる。
- テスト：`tests/server/test_main.cpp` の AW。座る場所・チケットの確認（はい／いいえ／30 秒切れ）・サブゲーム情報（データ API・保存と読み直し・旧形式の台詞）・使用中・歩けない・手牌の出し分け（本人だけ／観戦者に全員／終局は全員）・同じ内容を送り直さない・CPU の進行・人間の捨て／ツモ／ロン／鳴き／見送り／時間切れ・CPU の鳴き・CPU のロン・流局・局終了で席を立つ・ESC／離れる／マップ移動／切断で片付く・近づく／離れる・空卓の案内。盤面ロジック単体は `g++ -std=c++11 -O1 -I. tests/server/janjan_test.cpp -o /tmp/jt && /tmp/jt`。

## クライアント側（画面・操作）

- 受信（`SboCliRecvCmd.cpp` の `RecvDataProcJANSTATE`）：`CMD_JANSTATE` を `dwNpc` ごとに最大 16 卓ぶん覚える（近くの台。`JANSTATE_NONE` で消す。長さが 385 バイトでなければ捨てる）。座っているか（`IsJanSeated`）は「`byMySeat` が 0〜3 の卓を持っているか」。座っている間は `IsPuzzleSeated` と同じ箇所（キー処理・歩き・ショートカット・仮想パッド）を止める。
- 操作（`SboCliKeyProc.cpp` の `JanKeyProc`、中身は `JanKeyInput`）：左右＝手牌のカーソル（引いた牌も選べる。クライアントだけで動かしサーバーへは送らない）、X＝捨てる／操作の行で選んだ操作、ESC＝席を立つ（Z では立たない。スマホのキャンセルボタンは ESC を送る）。ロン／そろい／組そろい／ツモ上がり／見送りができる時は手牌の上に操作の行が出て、上キーで手牌の行と操作の行を行き来し、左右で選ぶ。組そろいで選び方が複数ある時は別々のボタン。自分の捨てる番は手牌の行、他人の捨て牌への申し出待ちは操作の行が既定。残り時間は `dwLimitMs` をクライアントが減らして出す。
- 描画（`SboCliDrawScreen.cpp` の `DrawJan`）：落ち物パズルと同じ座標・重なり順（下の層＝キャラの前、上の層＝ウィンドウの下）。卓は 224 ドット四方、牌は 16 ドット（回転しない）。各辺に手牌の帯（席0=下・席1=右・席2=上・席3=左）、内側を 4 つの箱（席0=右下・席1=右上・席2=左上・席3=左下）に分けて名前札と川（5 列×4 行。4 席とも同じ向き）、真ん中の帯に山の残り・手番・結果。座っている本人の手牌は画面下に固定の別枠（牌 32 ドット）。
- 仮想パッド：`PADSTATE_JAN`（0x100）。座っている間は「決定」「席を立つ」と十字キーだけ出す。
- 座る入口：`@j` の台の座る場所（`JanjanSeatOffset` の 4 か所）に立って S キー。

### 牌の絵（仮の割り当て）

牌 id 0〜15（組＝id÷4）に、町の顔ぶれとプヨンなどの敵から、正面向き・立ち止まりの 1 コマ（`SboGrpData/grp/char<ファイル番号>.png` の向き「下」の 1 コマ目）を仮に割り当てています。割り当ては `SboCliDrawScreen.cpp` の `s_aJanTileGrp` の 1 か所だけなので、差し替える時はこの表を変えます。
