# 土地取りすごろく 素材

Python 3.11 と Pillow 13 で `python gen.py` を実行すると各 PNG を再生成できます。
座標の原点は左上です。色数は完全透明の1色を含む RGBA の実測値です。

| ファイル | サイズ | 色数 |
|---|---:|---:|
| `land_cells.png` | 672×384 | 63 |
| `land_ui.png` | 256×128 | 18 |
| `preview_cells.png` | 2688×1536 | 63 |
| `preview_cells_half.png` | 336×192 | 63 |
