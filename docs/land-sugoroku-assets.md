# 土地取りすごろく 素材

Python 3.11 と Pillow 13 で `python gen.py` を実行すると各 PNG を再生成できます。
座標の原点は左上です。色数は完全透明の1色を含む RGBA の実測値です。

## 素材の一覧（SboGrpData/grp/）

| ファイル | サイズ | 内容 | 状態 |
|---|---|---|---|
| `land_cells.png` | 672×384・63色 | コマ絵（ドット絵）。96×96 を 7列×4行 | 使用中（`?landart=dot` で切り替え） |
| `land_ui.png` | 256×128・18色 | UI部品（ドット絵）。下の座標表 | 使用中 |
| `land_cells_illust_anime2.png` | 1344×768・不透明RGB | コマ絵（アニメ背景風）。192×192 を 7列×4行。主役を大きく中央に配置 | **既定**（起動時に 96×96 へ縮小して使う） |
| `land_cells_illust.png` | 1344×768・RGBA | コピック風（Pillow の描画）。角は透明 | 試作・未使用 |
| `land_cells_illust_gen.png` | 1344×768・RGB | コピック風（画像生成・可愛いデフォルメ寄り） | 試作・未使用 |
| `land_cells_illust_anime.png` | 1344×768・RGB | アニメ背景風の初版（遠景の町・手前に草地） | 試作・未使用（町の違いが小さく anime2 に差し替え） |

コマ番号の並び・町の特徴・地方の色調は、どの版も同じ（下の表）。イラスト版はどれも絵の中に文字なし、上1/3は空・下1/3は地面か水面で落ち着いた色。
アニメ背景版は、PR #373 のタイトル背景から塗りの見本を切り出して画像生成（`image_gen`）に参照画像として渡し、1コマずつ生成した（原画は作業フォルダ `sbo2003-land-assets` の `gen_raw_anime2`）。
ドット絵版は Python 3.11 と Pillow 13 の `gen.py` で再生成できる。座標の原点は左上。色数は完全透明の1色を含む RGBA の実測値。
