# 迷路対戦（7×7の2人対戦サブゲーム）

向かい合わせの辺から始め、相手側の辺のどこかに先に着いた方が勝ちの対戦ゲームです。1手は「十字に1マス進む」か「壁を1枚置く」のどちらか。
台に席が2つあり、片方だけ座っている間は **ひとり練習**（相手は不在で、手番は自動で飛ばす）、2人そろえば **2人対戦**、サブゲーム情報でCPU強さを決めた台では **CPU対戦** もできます。

## ルール（`common/MazeAttack.h`）

- 盤は7×7マス。下側の人は (3,6) から上端の行へ、上側の人は (3,0) から下端の行へ向かう。
- 壁は各6枚。2マス分の長さで、マスとマスの境目に置く（横壁・縦壁）。置いた壁は動かせない。
- 相手のコマのマスには進めず、壁も飛び越えられない。
- 壁を置けない場合：盤からはみ出す／同じ向きで重なる（3マス分に延びる）／同じ交点で十字に交差する／どちらかのゴールへの道が1本も無くなる。
- 動くことも壁を置くこともできない時は手番を飛ばす。

## 台の作り方

台の設定は **サブゲーム情報**（管理者ウィンドウの「サブゲーム情報」。種別「迷路対戦の台」＝`SUBGAMEID_MAZETABLE`＝7。6 はピンボール用に空けてある。`SUBGAME_MAZETABLEINFO`）に持ちます。
迷路ダンジョンの `SUBGAMEID_MAZE`（2）とは別物です。台NPCは、管理者ウィンドウで NPC を置き、台詞を次にします。

```
@k<サブゲーム情報の番号>
```

番号はダンジョン受付の `@d<番号>` と同じ指し方（サブゲーム情報の一覧の番号。0 から）。旧書式 `@k<dx>,<dy>,…` は廃止しました。
番号が存在しない・種別が「迷路対戦の台」でない・数字以外が混ざる（`@k` だけ・旧書式など）時は、台ではないものとして無視します（座れない）。
設定を変えると、待機中の台にはすぐ効きます（遊んでいる間は、終わって待機中に戻ってから）。

| 項目（`SUBGAME_MAZETABLEINFO`） | 意味 | 既定 |
|---|---|---|
| `szName` | 台の名前（管理用の呼び名。ゲーム中は使わない） | 空 |
| `chDx`, `chDy` | 盤（10×10タイル＝320×320ドット。マス32・通り道16）の左上が台NPCのマスの左上から何タイルか（-60〜60） | -5,-9（盤の中央が席の列、盤の下端が台NPCのマス） |
| `chSdx`, `chSdy` | 座る場所1＝席1（プレイヤー0＝下側）。台NPCのマスからの相対位置（-60〜60） | 0,+1 |
| `chSdx2`, `chSdy2` | 座る場所2＝席2（プレイヤー1＝上側）。同じく相対位置。既定は盤の上端の1行上 | 0,-10 |
| `wFloorA`, `wFloorB` | マスに使うマップパーツID（市松に交互）。Bが0ならAだけの単色。どちらも0ならコード描画の床 | 0,0 |
| `wGap` | 壁の通り道（16ドット幅の溝と交差点）の地に使うマップパーツID。パーツ（32×32）の中央16×16を敷き詰める。0なら暗い単色 | 0 |
| `byCpuLevel` | 0＝CPUなし（従来のひとり練習）、1=よわい・2=ふつう・3=つよい。1以上の台は、人がひとりで座った時にCPU対戦を聞く（下の「CPU対戦」） | 0 |
| `wCpuGrpID` | CPUのコマに使うキャラ画像（NPCの見た目 `wGrpID` と同じ意味）。0なら色付きの丸 | 0 |
| `szCpuName` | CPUの名前表示。空なら「CPU」。勝敗のお知らせ（「ロボの勝ち！」など）にも使う | 「CPU」 |
| `wTicketItemID`, `byTicketNum` | 参加チケットのアイテム番号と必要枚数。`byTicketNum` が 1 以上の台は有料で、席のマスでチケットを使って座る（下の「チケットで参加する台」）。0 なら無料でSキー | 0,0 |

- パーツIDがパーツ数以上（範囲外）の指定は、その部分だけコード描画に戻ります。席2が盤の外（マップの端など）にはみ出す場合の扱いは決めていない（収まる所に置く）。
- 既定の台は、台NPCの上に10マス以上の空きが必要です。チケットの台（`byTicketNum`≧1）は席のマスでコマンド→道具→チケットを使って座ります（下の「チケットで参加する台」）。落ち物パズルとは同時に座れません。
- 保存は `SboDataSubGameInfo.dat` の列名方式（`SboSvrSaveLoadSubGameInfo.cpp` の `s_aszNameMAZETABLE`）。列が足りない古いデータは、足りない項目が既定値になります。
- データAPI（`subGame`）で読み書きできます：`{"byType":7,"detail":{…}}` で追加（`detail` を省くと全部既定値）、`{"detail":{"byCpuLevel":2}}` で変更、`{"byType":0}` で消す（その番号を指す台NPCは台でなくなる）。範囲外の値は断ります。
- クライアントは台の設定を持ちません。盤の位置・席の位置（`sSeatX/Y`）・CPUの見た目（`wCpuGrpID`・`szCpuName`）は、サーバーが送る `CMDPARA_MAZESTATE` から読みます。
  S キーは、届いている盤の席の位置に立っている時に台NPCへ話しかけ（`CMD_TALKRAND`）、座れるかの判定はサーバーが行います。
  席の位置は台の近くにいる間だけ届くので、席2が遠い台でも、盤が見える距離まで近づけば座れます（台NPCが画面の外でも可）。
- 対戦中、画面の外にいる相手のコマは、絵と名前が分からないので色付きの丸と「相手」で描きます。

### 管理者ウィンドウでの設定（`SboCli/src/AdminWindowOld/AdminDlgEtcSubGameEditMazeTable.cpp`）

管理者ウィンドウ（管理者ログイン後 x,x）のメニュー「その他」→「サブゲーム情報」で、一覧の「追加」を押して新しい番号を作り、行を選んで編集を開きます。

1. 種別のコンボから「迷路対戦の台」を選ぶ。切り替えた時点で既定値（盤の位置 -5,-9／座る場所 0,1 と 0,-10／CPU名「CPU」）が入ります。
2. 台の名前、盤の位置 X・Y、座る場所1・2 の X・Y（どれも台NPCからの相対タイル。-60〜60）、CPU強さ（なし／よわい／ふつう／つよい）、CPUの名前を入れる。
3. 床パーツA・B・隙間パーツ・CPUのキャラ画像は、番号を直接入れるか、横の「選択」ボタンで選びます。
   床パーツ・隙間は既存の「マップパーツ選択」、CPUのキャラ画像は既存の「キャラ画像選択」が開きます。番号を選ぶと欄に入り、横に小さなプレビュー（パーツは32×32、CPUの絵は下向き1コマ）が出ます。番号を手で直してもプレビューは変わります。
   CPUの絵に選べるのは通常のキャラ画像（選択ウィンドウの種別の一番上）だけです（`wCpuGrpID` は NPC の `wGrpID` と同じ意味のため）。
4. OK で保存すると、一覧の情報欄に出ます（もう一度開くと値が残っています）。
5. 台NPCの台詞を `@k<その番号>` にする。

座っている人のコマは、どのキャラでも本人が普段描かれる絵（変身中は変身後の絵。16×32・32×32・48×48・戦場ゲームの絵も）で描きます。CPUのコマは、`wCpuGrpID` が 0 でなければそのキャラ画像（向きは盤の進行方向）、0 なら色付きの丸と名前（`szCpuName`。空なら「CPU」。強さの数だけ ★ が付く）です。

## チケットで参加する台

落ち物パズルのコイン（`docs/falling-puzzle.md`）と同じ流れです。サブゲーム情報の `wTicketItemID`（アイテム番号）と `byTicketNum`（必要枚数）を入れた台は有料になります。

- **座り方**：席のマス（座る場所1・2）に立って、コマンド→道具→そのチケットを「使う」。足りていれば座る（`ItemProc` → `MazeUseItem` → 座る処理）。席以外のマスで使っても何も起きない（アイテムの説明文のまま・チケットは減らない）。
- **S キー**：有料の台では座れず、「チケットを使って始めます。コマンドの道具からチケットを使ってください。」と出るだけ（クライアントは今まで通り席に立って S を送るだけで、案内はサーバーが出す）。
- **足りない時**：「チケットがありません。」と出て座れず、枚数も減らない（確認を出す前に調べ、取り上げる直前にもう一度調べる）。
- **取り上げるタイミング**：座る時。CPU対戦・乱入・交代の確認がある時は「はい」を受けてから必要枚数を取り上げ（「チケットをN枚使いました。」、持ち物は本人の画面へ送り直す）、「いいえ」・30秒たって無効になった時は減らない。
  有料の台の CPU 確認だけは「いいえ＝座らない」（無料の台のようにひとり練習にはならない。有料でただ練習できてしまうのを避けるため）。
- **チケットのアイテム**：管理者ウィンドウの「アイテム」で、効果なし（`ITEMTYPE_NONE`）の普通のアイテムを作る（名前は「迷路チケット」など）。座る時に台がサーバー側で取り上げて消すので、アイテム自体に消える設定は要らない。
- **配布係**：落ち物パズルのコイン配布係と同じ。会話データ（`@tNNN`）の NPC を置き、会話セットの行の「話した後に渡すアイテム」にこのチケットを入れる（`wGiveItem`。毎回渡すので何度でももらえる。一度きりにしたい時は印の条件で組む。持ち物がいっぱいなら預かり所へ入る）。迷路の台の側に配布の仕組みは要らず、台と配布係は別のNPC（台詞 `@k<番号>` と `@t<番号>`）。
  例：台NPC（台詞 `@k0`、サブゲーム情報0番＝`wTicketItemID`:12・`byTicketNum`:2）と、配布係NPC（台詞 `@t5`、会話データ5番の行に「話した後に渡すアイテム＝12」）を置く。配布係に話して2枚もらい、台の席で使うと座れる。
- 管理者ウィンドウ（サブゲーム情報の「迷路対戦の台」）では、アイテムの一覧（名前つき）から選び、枚数を入れる。データAPI（`subGame` の `detail`）では `wTicketItemID`・`byTicketNum`（0〜99。範囲外は断る）。
- 保存は列名方式の最後に足した2列。列が無い古い保存データは、チケットなし（0）＝無料になります。

## 遊び方

- 席のマスに立って S キーで座る（無料の台。チケットの台は下の「チケットで参加する台」）。席1に座るとプレイヤー0（下側）、席2に座るとプレイヤー1（上側）。座っている間は視点が盤の中央に固定され、盤の全体が1画面に収まる。歩行・特技・ショートカットは止まる。
- 進む（MOVE）：矢印キーでコマを1マス動かす。X で壁モードへ。ESC で席を立つ。
- 壁（WALL）：矢印でカーソル（6×6の交点）、Z で横/縦の切り替え、X で置く（置けない所は赤✕）、ESC で進むに戻る。
- ひとり練習で勝つと3秒ほど盤を見せたあと、座ったまま自動で最初からやり直す。

### 2人対戦（`SboSvrMaze.cpp`。お手本は落ち物パズルの対戦）

- ひとり練習中のところへもう一方の席に座ろうとすると、先に「○○さんが遊んでいます。乱入して対戦しますか？（「いいえ」で座りません）」と聞く（会話の「はい・いいえ」`@y` と `CMD_TALKANSWER` を流用。サーバーは `MazeSit` の `nChoice`、答えは `MazeAnswer`。30秒で無効）。はい＝盤を初期化して対戦開始、いいえ＝座らない。
- 開始は3・2・1のカウントダウンのあと（`MAZE_VS_COUNTDOWN_SEC`）。カウントダウン中は操作無効。
- 手番はプレイヤー0から始まり、1手ごとに交代。手番でない人の `CMD_MAZEKEY` は無視（状態を送り直す）。対戦中の「やり直す」も無視。
- 1手の制限時間は `MAZE_TURN_MS`（30秒）。切れたらその手番を飛ばし、同じ人が連続で `MAZE_TIMEOUT_MAX`（3）回切らしたら不戦敗。指すと連続回数は0に戻る。残り秒は1秒ごとに `CMD_MAZESTATE` で送り直す。
- 勝敗が決まると両者へ「○○の勝ち！」（キャラ名のシステムメッセージ）。盤を3秒見せたあと自動で初期化し、カウントダウンから続けて対戦する（先手は1局ごとに交代）。
- 席を立つ（ESC）・切断・マップ移動（座る場所から離れる）・倒れた時は、残った側の勝ちで終わり、残った人はそのままひとり練習に戻る（盤は初期化）。
- 座っている間の歩行・特技の制限は両席に効く。落ち物パズルとは同時に座れない。近くの人（観戦）への送り方は今まで通り。
- 状態 `CMDPARA_MAZESTATE` の対戦用の欄（`byState` の `MAZESTATE_VS`・`MAZESTATE_COUNT`、`byCount`・`byTimeLeft`・`byTimeouts[2]`・`byHasName[2]`・`dwTurnChar`）の意味は `common/TypedefCommon.h` のコメントを見る。
- 近くを歩く人にも、待機中の台の盤が見える（落ち物パズルと同じ仕組み）。
- スマホは仮想パッドで同じ操作ができる。

### CPU対戦（`SboSvrMaze.cpp`・思考は `common/MazeAttack.h` の `MazeCpuChoose`）

サブゲーム情報の `byCpuLevel`（1=よわい・2=ふつう・3=つよい）を入れた台だけ。0 の台は今まで通り確認なしでひとり練習。

- よわい：7割は最短路の1歩、残りはでたらめに進む／壁を置く。ふつう：1手先まで見て、有利なら進み不利なら壁。つよい：候補を絞って2手先まで読む。
- **流れ**：人がひとりで座る（相手の席が空）と、座った本人に「CPUと対戦しますか？（「いいえ」でひとりで練習します）」と聞く（乱入確認と同じ `@y`・`CMD_TALKANSWER`。30秒で無効）。はい＝CPU対戦、いいえ＝ひとり練習。
- CPU対戦：空いている側の席をCPUが受け持つ（仮想プレイヤー。名前は `szCpuName`（既定「CPU」）、キャラIDは無効値・`byHasName`=0）。座った時点で3・2・1のカウントダウンのあと開始。手番は交互で、先手はプレイヤー0。
- 人の1手は30秒（時間切れの手飛ばし・3回続けて不戦敗は人だけ）。CPUは時間切れなし。CPUの手番は、サーバーのタイマーで1.0〜2.0秒（乱数。乱数の状態は台ごと）考えたあと `MazeCpuChoose` の1手（進む／壁／パス）を、人と同じ `Move`/`PlaceWall`/`Pass` の検証で指す。
- 勝敗は「（CPUの名前）の勝ち！」「○○の勝ち！」。3秒見せてから自動で次の対戦（先手交代・CPU継続）。
- 人が席を立つ・切断・マップ移動・倒れた時はCPU対戦を終え、盤を初期化して待機中に戻る。
- **交代**：CPU対戦中にCPU側の席へ別の人が座ろうとすると、その人に「CPUと対戦中です。交代して対戦しますか？」と聞く。はい＝CPUを外して盤を初期化し、人対人の対戦（カウントダウンのあと開始。元から座っている人は残る）。いいえ＝座らない。
- 通信：`CMDPARA_MAZESTATE` の `byState` に `MAZESTATE_CPU`（CPU対戦中。`MAZESTATE_VS` も立つ）、`byCpuLevel` に台のCPU強さ（待機中の台にも入る）、`wCpuGrpID`・`szCpuName` にCPUのキャラ画像と名前。CPUの席は `dwChar`=`MAZE_NOCHAR`。
- 見た目（`wCpuGrpID` が 0 の時）：CPUのコマは色付きの丸に「C」、名前は「CPU★」（★の数＝強さ）。手番は「あなたの番」「CPUの番」、観戦の人にも見える。待機中の台と、CPU対戦中を見ている人には、盤の外に小さく「CPU対戦（つよい）」などを出す。

## 盤の見た目

盤は320×320ドット。床・隙間の絵はサブゲーム情報のマップパーツ（`wFloorA`・`wFloorB`・`wGap`）から（`DrawMazeBoard`）。マス32ドット（キャラの実寸）、マスの間の通り道＝壁の太さ16ドット。マス(x,y)の左上は盤ドット(48x,48y)。横壁(x,y)は縦48y+32〜+48・横48x〜48x+80、縦壁はその縦横を入れ替えた形（交差点16×16も壁の一部）。視点は盤ドット(160,160)に固定。

## 壁の絵（system.png のどこに何があるか）

壁は `SboGrpData/grp/system.png`（256×256・索引色）に描き足した 16×16 の絵で描く（`SboCliDrawScreen.cpp` の `MAZEART_*` に同じ表がある）。
読めない・描き足した場所が透明な時は、コード描画のレンガ風に戻る。置かれた壁と壁カーソル（半透明）は同じ絵。
x=224 がプレイヤー0（茶のレンガ）、x=240 がプレイヤー1（灰の石レンガ）。y は次の通り。

| y | 絵 | 使い方 |
|---|---|---|
| 128 | 横壁の左端 | 横壁（80×16）は 左端・中・交差点・中・右端 の5枚 |
| 144 | 横壁の中 | |
| 160 | 横壁の右端 | |
| 176 | 縦壁の上端 | 縦壁（16×80）は 上端・中・交差点・中・下端 の5枚 |
| 208 | 縦壁の中 | （y=192〜207 は元からある絵があるので飛ばした） |
| 224 | 縦壁の下端 | |
| 240 | 交差点（壁の真ん中の石） | 横壁・縦壁の真ん中の1枚（マスの隙間の位置） |

元からある絵（窓の枠・矢印・アイテムや状態のアイコン・HP/マナのバー・隠れパーツの枠など）は触っていない。描き足した14枚の場所（x=224〜255 の右端2列）は元から黒（透過）で、ほかのコードも使っていなかった。
透過色は黒 (0,0,0)（HP枠だけ (40,40,40)）なので、壁の絵には黒を使っていない。パレットは元のまま、未使用の索引（171〜181）に壁の10色を足した。

## 通信・実装の場所

- `CMD_MAZEKEY`（クライアント→サーバー：進む・壁を置く・席を立つ）、`CMD_MAZESTATE`（サーバー→クライアント：盤の状態）。
- サーバー：`SboSvr/src/SboSvrMaze.cpp`。台詞の番号の読み方・設定の範囲の丸めは `common/MazeTable.h`、台の設定は `SUBGAME_MAZETABLEINFO`（`common/TypedefCommon.h`）。
- クライアント：`SboCliDrawScreen.cpp`（盤・コマ・壁の描画）、`SboCliKeyProc.cpp`（操作）、`SboCliRecvCmd.cpp`（状態の受信）。
- テスト：`tests/server/maze_attack_test.cpp`（ルール）、`tests/server/test_main.cpp` の `TestMaze`（台・通信・CPU対戦）。
