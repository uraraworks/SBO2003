# 迷路対戦（7×7の2人対戦サブゲーム）

向かい合わせの辺から始め、相手側の辺のどこかに先に着いた方が勝ちの対戦ゲームです。1手は「十字に1マス進む」か「壁を1枚置く」のどちらか。
台に席が2つあり、片方だけ座っている間は **ひとり練習**（相手は不在で、手番は自動で飛ばす）、2人そろえば **2人対戦** です。CPU対戦は次の段階です。

## ルール（`common/MazeAttack.h`）

- 盤は7×7マス。下側の人は (3,6) から上端の行へ、上側の人は (3,0) から下端の行へ向かう。
- 壁は各6枚。2マス分の長さで、マスとマスの境目に置く（横壁・縦壁）。置いた壁は動かせない。
- 相手のコマのマスには進めず、壁も飛び越えられない。
- 壁を置けない場合：盤からはみ出す／同じ向きで重なる（3マス分に延びる）／同じ交点で十字に交差する／どちらかのゴールへの道が1本も無くなる。
- 動くことも壁を置くこともできない時は手番を飛ばす。

## 台の作り方

管理者ウィンドウで NPC を置き、台詞を次にします（後ろは省略でき、空欄も既定）。

```
@k<dx>,<dy>,<sdx>,<sdy>,<床A>,<床B>,<隙間>,<sdx2>,<sdy2>
```

| 項目 | 意味 | 既定 |
|---|---|---|
| dx, dy | 盤（10×10タイル＝320×320ドット。マス32・通り道16）の左上が台NPCのマスの左上から何タイルか | -5,-9（盤の中央が席の列、盤の下端が台NPCのマス） |
| sdx, sdy | 席1（プレイヤー0＝下側）の座る場所（台NPCのマスからの相対位置） | 0,+1 |
| 床A, 床B | マスに使うマップパーツID（市松に交互）。Bを省略したらAだけの単色。どちらも 0・省略ならコード描画の床 | 0,0 |
| 隙間 | 壁の通り道（16ドット幅の溝と交差点）の地に使うマップパーツID。パーツ（32×32）の中央16×16を敷き詰める。0・省略なら暗い単色 | 0 |
| sdx2, sdy2 | 席2（プレイヤー1＝上側）の座る場所（台NPCのマスからの相対位置）。既定は盤の上端の1行上 | 0,-10 |

パーツIDがパーツ数以上（範囲外）の指定は、その部分だけコード描画に戻ります。例：`@k,,,,5,6,7` は床にパーツ5と6（市松）、隙間にパーツ7。`@k,,,,,,,3,-10` は席2を台NPCの右3マス・上10マスにする。席2が盤の外（マップの端など）にはみ出す場合の扱いは決めていない（収まる所に置く）。

台NPCの上に10マス以上の空きが必要です。無料の台のみ（コインは未対応）。落ち物パズルとは同時に座れません。

クライアントは、席2が画面（15×15）の外で台NPCが見えない時、サーバーから届いた盤の位置から「盤の中央の列・上端の1行上」を既定の席2とみなしてSキーを送ります（座れるかの判定はサーバー）。席2を既定以外にした台で台NPCが見えない時は、Sキーが届かず座れません。
対戦中、画面の外にいる相手のコマは、絵と名前が分からないので色付きの丸と「相手」で描きます。

## 遊び方

- 席のマスに立って S キーで座る。席1に座るとプレイヤー0（下側）、席2に座るとプレイヤー1（上側）。座っている間は視点が盤の中央に固定され、盤の全体が1画面に収まる。歩行・特技・ショートカットは止まる。
- 進む（MOVE）：矢印キーでコマを1マス動かす。X で壁モードへ。ESC で席を立つ。
- 壁（WALL）：矢印でカーソル（6×6の交点）、Z で横/縦の切り替え、X で置く（置けない所は赤✕）、ESC で進むに戻る。
- ひとり練習で勝つと3秒ほど盤を見せたあと、座ったまま自動で最初からやり直す。

### 2人対戦（`SboSvrMaze.cpp`。お手本は落ち物パズルの対戦）

- ひとり練習中のところへもう一方の席に座ろうとすると、先に「○○さんが遊んでいます。乱入して対戦しますか？（「いいえ」で座りません）」と聞く（会話の「はい・いいえ」`@y` と `CMD_TALKANSWER` を流用。サーバーは `MazeSit` の `nChoice`、答えは `MazeAnswer`。30秒で無効）。はい＝盤を初期化して対戦開始、いいえ＝座らない。
- 開始は3・2・1のカウントダウンのあと（`MAZE_VS_COUNTDOWN_SEC`）。カウントダウン中は操作無効。
- 手番はプレイヤー0から始まり、1手ごとに交代。手番でない人の `CMD_MAZEKEY` は無視（状態を送り直す）。対戦中の「やり直す」も無視。
- 1手の制限時間は `MAZE_TURN_MS`（30秒）。切れたらその手番を飛ばし、同じ人が連続で `MAZE_TIMEOUT_MAX`（3）回切らしたら不戦敗。指すと連続回数は0に戻る。残り秒は1秒ごとに `CMD_MAZESTATE` で送り直す。
- 勝敗が決まると両者へ「○○の勝ち！」（キャラ名のシステムメッセージ）。盤を3秒見せたあと自動で初期化し、カウントダウンから続けて対戦する（先手は1局ごとに交代）。
- 席を立つ（ESC）・切断・マップ移動（座る場所から離れる）・倒れた時は、残った側の勝ちで終わり、残った人はそのままひとり練習に戻る（盤は初期化）。
- 座っている間の歩行・特技の制限は両席に効く。落ち物パズルとは同時に座れない。近くの人（観戦）への送り方は今まで通り。
- 状態 `CMDPARA_MAZESTATE` の対戦用の欄（`byState` の `MAZESTATE_VS`・`MAZESTATE_COUNT`、`byCount`・`byTimeLeft`・`byTimeouts[2]`・`byHasName[2]`・`dwTurnChar`）の意味は `common/TypedefCommon.h` のコメントを見る。
- 近くを歩く人にも、待機中の台の盤が見える（落ち物パズルと同じ仕組み）。
- スマホは仮想パッドで同じ操作ができる。

## 盤の見た目

盤は320×320ドット。床・隙間の絵は台詞のマップパーツから（`DrawMazeBoard`）。マス32ドット（キャラの実寸）、マスの間の通り道＝壁の太さ16ドット。マス(x,y)の左上は盤ドット(48x,48y)。横壁(x,y)は縦48y+32〜+48・横48x〜48x+80、縦壁はその縦横を入れ替えた形（交差点16×16も壁の一部）。視点は盤ドット(160,160)に固定。

## 壁の絵（system.png のどこに何があるか）

壁は `SboGrpData/grp/system.png`（256×256・索引色）に描き足した 16×16 の絵で描く（`SboCliDrawScreen.cpp` の `MAZEART_*` に同じ表がある）。
読めない・描き足した場所が透明な時は、コード描画のレンガ風に戻る。置かれた壁と壁カーソル（半透明）は同じ絵。
x=224 がプレイヤー0（茶のレンガ）、x=240 がプレイヤー1（灰の石レンガ）。y は次の通り。

| y | 絵 | 使い方 |
|---|---|---|
| 128 | 横壁の左端 | 横壁（80×16）は 左端・中・交差点・中・右端 の5枚 |
| 144 | 横壁の中 | |
| 160 | 横壁の右端 | |
| 176 | 縦壁の上端 | 縦壁（16×80）は 上端・中・交差点・中・下端 の5枚 |
| 208 | 縦壁の中 | （y=192〜207 は元からある絵があるので飛ばした） |
| 224 | 縦壁の下端 | |
| 240 | 交差点（壁の真ん中の石） | 横壁・縦壁の真ん中の1枚（マスの隙間の位置） |

元からある絵（窓の枠・矢印・アイテムや状態のアイコン・HP/マナのバー・隠れパーツの枠など）は触っていない。描き足した14枚の場所（x=224〜255 の右端2列）は元から黒（透過）で、ほかのコードも使っていなかった。
透過色は黒 (0,0,0)（HP枠だけ (40,40,40)）なので、壁の絵には黒を使っていない。パレットは元のまま、未使用の索引（171〜181）に壁の10色を足した。

## 通信・実装の場所

- `CMD_MAZEKEY`（クライアント→サーバー：進む・壁を置く・席を立つ）、`CMD_MAZESTATE`（サーバー→クライアント：盤の状態）。
- サーバー：`SboSvr/src/SboSvrMaze.cpp`。台詞の解析は `common/MazeTable.h`。
- クライアント：`SboCliDrawScreen.cpp`（盤・コマ・壁の描画）、`SboCliKeyProc.cpp`（操作）、`SboCliRecvCmd.cpp`（状態の受信）。
- テスト：`tests/server/maze_attack_test.cpp`（ルール）、`tests/server/test_main.cpp` の `TestMaze`（台・通信）。
