# リサイクルボックス（おすそわけの共有の箱）

プレイヤーがいらなくなった品を入れておき、ほしい人がお金なしでもらっていける共有の箱です。
お金のやり取りは取引所（`docs/market.md`）、お金を取らない「おすそわけ」はこの箱、と住み分けています。

## 決まりごと（2026-11-17 決定）

| 項目 | 内容 |
| --- | --- |
| 置き方 | NPC の台詞を `@d` にすると箱になる（話しかけると開く）。`@d` はほかの印（`@5` `@6` `@7` `@a` `@b` `@c` `@g` `@m` `@q` `@r` `@t`・制御コード）と重ならない空きの印 |
| 箱ごとの中身 | NPC の永続 ID（`npcId` / `dwNpcID`。再起動しても変わらない番号）ごとに別々。NPC 番号が無い NPC（発生した敵・プレイヤー）は箱にならない |
| 使える場所 | 箱から 3 マス以内（同じマップ・同じ空間）。サーバーが毎回確かめる |
| 入る数 | 1 つの箱に 20 種類まで。同じ品は預かり所のように個数でまとめ、1 種類 255 個まで。いっぱいなら断る（種類がいっぱいでも、すでにある品を足すのはよい） |
| 入れる | 手持ちの品を選び、同じ品を何個入れるかを選ぶ。手持ちは 1 枠に 1 個なので、同じ種類を何枠持っているか（装備中の分は除く）が上限 |
| 入れられない品 | 装備中の品・依頼の品（`QuestIsQuestItem`）・大事な物（`ITEMFLG_IMPORTANT`。別の欄なので元から手持ちに出ない）・取り引きできない品（`ITEMFLG_TRADE` = 取り引き不可の印）。お金は入れられない |
| もらう | 1 回に 1 個（個数は選ばない）。手持ちに空きが無い時は断る |
| 1 日の数 | 1 アカウントが 1 日にもらえるのは 3 個まで（`RECYCLE_DAYLIMIT`）。日本時間の 0 時に戻る。画面に「今日はあと○個もらえます」と出る |
| 自分の品 | 自分が入れた品もそのままもらえる（1 日の数には数える） |
| 記録 | 誰（アカウント・キャラ名）が・いつ・どの箱で・何を何個入れた／もらったかを、新しい 1000 件（`RECYCLE_LOGMAX`）まで残す |

## 画面

箱の NPC に話しかけると、サーバーへ中身を頼み、届くとメニューが出ます。

1. **入れる**：手持ちを品の種類ごとにまとめた一覧（品名と「入れられる数」。装備中・取り引き不可は灰色）。選ぶと個数を選ぶ（↑↓で増減、←で 1 個・→で最大）→ 決定で入れる。
2. **もらう**：箱の中身の一覧（品名と個数）。選ぶと 1 個もらい、一覧を取り直して続けてもらえる。台詞に「今日はあと○個もらえます」が出る。
3. **やめる**

一覧は預かり所と同じ作りで、行数を超えると上下に ▲▼ が出ます（`DrawListScrollMark`）。一覧の横に、カーソルの品の詳細が出ます。

## 通信（`common/TypedefCommon.h`）

- `CMD_RECYCLELIST`（中身）・`CMD_RECYCLEPUT`（入れる）・`CMD_RECYCLETAKE`（もらう）。プレイヤー用なので、管理者用の判定から外してあります。
- 要求は `CMDPARA_RECYCLE`（`wItemID`・`byCount`・話しかけた箱の `dwNpcTblID`）。結果も同じ形で、`byResult`（`RECYCLERES_*`）・今日あと何個もらえるか（`byLeft`）が付きます。中身の返事は `CMDPARA_RECYCLELIST`（種類の数ぶんだけ届く）。
- 結果の後に `CMD_CHARITEM`（手持ちの更新）が届きます。

## 保存

サーバーの `SBODATA/SboDataRecycle.dat`（取引所・依頼と同じ列名つきの形式。1 つの表に `byKind` で分けて入れる）。

- `byKind` 0 … 箱の中身：`dwNpcID`・`wItemID`・`byCount`
- `byKind` 1 … 今日もらった数：`szAcc`・`dwDay`（日本時間の日付。1970/1/1 から数えた日数）・`byCount`。今日でない日付の行は保存しない（0 個と同じ）
- `byKind` 2 … 記録：`dwTime`・`szAcc`・`szName`・`dwNpcID`・`byLogKind`（0=入れた・1=もらった）・`wItemID`・`byCount`（古い順）

1 日の数え方は「日本時間（UTC+9）の日付が変わったら 0 個に戻る」で、時刻から日付を `(秒 + 9 時間) / 1 日` で求めます。
データが 1 件も無く、ファイルも無い時は作りません。

## 管理者

読むだけです（箱の中身も記録も管理者は変えません）。

- データ API `/api/data/recycle`（MCP は `sbo_recycle`、管理ページ用は `/api/admin/data/recycle`）。詳しくは `docs/ai-data.md` の「リサイクルボックス」。
- 管理ページ（`/admin`）の「リサイクル」タブ：箱ごとの中身・今日もらった人・記録（アカウント・キャラ名・品で絞り込み）。
