# リサイクルボックス（おすそわけの共有の箱）

プレイヤーがいらなくなった品を入れておき、ほしい人がお金なしでもらっていける共有の箱です。
お金のやり取りは取引所（`docs/market.md`）、お金を取らない「おすそわけ」はこの箱、と住み分けています。

## 決まりごと（2026-11-17 決定）

| 項目 | 内容 |
| --- | --- |
| 置き方 | マップに置く箱。マップの「印で変わるマス」（`map` の `swaps`）の 3 つ目の種類 `kind` 2「リサイクル箱」として足す（管理ページ「マップ確認」の「印で変わるマス・宝箱・リサイクル箱」か、データ API の `swaps`）。NPC は使わない（台詞 `@d` の箱は無くなった） |
| 1 行に持つもの | 箱のマス `x`・`y`、閉じた絵（ふだんの**マップのパーツそのもの**）、開いた絵のパーツ `wParts`、管理用のメモ `szMemo`（プレイヤーには出ない）、箱番号 `wBoxNo` |
| 箱番号 | 全マップ通しで重ならない 1〜1024 の番号（`MAX_RECYCLEBOX`）。足す時に省くと自動で振る。**消した番号は使い回さない**（マップごとに使った最大の番号 `wBoxHigh` を保存して覚える）。宝箱番号（`wChestNo`）とは別の番号空間 |
| 箱ごとの中身 | 箱番号ごとに別々 |
| 開け方 | 箱の正面で S キーで調べる（クライアントは、調べられるマスとして届いた箱の前でだけ要求を送る）。その人の画面だけ箱が開いた絵（`wParts`）になり、メニューの窓が開く。窓を閉じると閉じた絵に戻る。ほかの人の画面は変わらない |
| 使える場所 | 箱のマスから 3 マス以内（同じマップ）。**箱のマスから測る**。サーバーが毎回確かめ、離れていたら断って箱を閉じる。マップを移った・箱を消した場合も、開いた記憶を捨てる |
| 入る数 | 1 つの箱に 20 種類まで。同じ品は預かり所のように個数でまとめ、1 種類 255 個まで。いっぱいなら断る（種類がいっぱいでも、すでにある品を足すのはよい） |
| 入れる | 手持ちの品を選び、同じ品を何個入れるかを選ぶ。手持ちは 1 枠に 1 個なので、同じ種類を何枠持っているか（装備中の分は除く）が上限 |
| 入れられない品 | 装備中の品・依頼の品（`QuestIsQuestItem`）・大事な物（`ITEMFLG_IMPORTANT`。別の欄なので元から手持ちに出ない）・取り引きできない品（`ITEMFLG_TRADE` = 取り引き不可の印）。お金は入れられない |
| もらう | 1 回に 1 個（個数は選ばない）。手持ちに空きが無い時は断る |
| 1 日の数 | 1 アカウントが 1 日にもらえるのは 3 個まで（`RECYCLE_DAYLIMIT`）。日本時間の 0 時に戻る。画面に「今日はあと○個もらえます」と出る |
| 自分の品 | 自分が入れた品もそのままもらえる（1 日の数には数える） |
| 記録 | 誰（アカウント・キャラ名）が・いつ・どの箱で・何を何個入れた／もらったかを、新しい 1000 件（`RECYCLE_LOGMAX`）まで残す |

## 画面

箱を調べると、サーバーが箱を開いた絵にして、中身と一緒に「開いた」知らせを送ってくる（`CMD_RECYCLELIST` の `byOpen` が 1）ので、メニューが出ます。窓の中の頼みごと（もらう一覧の取り直し・入れる・もらう）は、そのまま開いている箱に対して送ります。

1. **入れる**：手持ちを品の種類ごとにまとめた一覧（品名と「入れられる数」。装備中・取り引き不可は灰色）。選ぶと個数を選ぶ（↑↓で増減、←で 1 個・→で最大）→ 決定で入れる。
2. **もらう**：箱の中身の一覧（品名と個数）。選ぶと 1 個もらい、一覧を取り直して続けてもらえる。台詞に「今日はあと○個もらえます」が出る。
3. **やめる**（Z キーも同じ。窓が閉じて、箱は閉じた絵に戻る）

一覧は預かり所と同じ作りで、行数を超えると上下に ▲▼ が出ます（`DrawListScrollMark`）。一覧の横に、カーソルの品の詳細が出ます。

## 通信（`common/TypedefCommon.h`）

- `CMD_RECYCLELIST`（中身）・`CMD_RECYCLEPUT`（入れる）・`CMD_RECYCLETAKE`（もらう）・`CMD_RECYCLECLOSE`（窓を閉じた）。プレイヤー用なので、管理者用の判定から外してあります。
- 箱を開くのは `CMD_CHECKEVENT`（S キーの調べる）。サーバーは目の前が箱の行なら、その人の `wRecycleBox`（いま開いている箱の番号。保存しない）に箱番号を入れ、`CMD_MAPSWAP` を本人にだけ送り直し（開いた絵）、位置を送って待ちを解き、中身の一覧（`byOpen`=1）を送る。`byFlg` は、閉じている箱が 2（調べると開く）、開いている箱が 1（差し替え中）。
- 要求は `CMDPARA_RECYCLE`（`wItemID`・`byCount`。どの箱かは、開いている箱をサーバーが覚えている）。結果も同じ形で、`byResult`（`RECYCLERES_*`）・今日あと何個もらえるか（`byLeft`）が付きます。中身の返事は `CMDPARA_RECYCLELIST`（種類の数ぶんだけ届く）。
- 結果の後に `CMD_CHARITEM`（手持ちの更新）が届きます。

## 保存

サーバーの `SBODATA/SboDataRecycle.dat`（取引所・依頼と同じ列名つきの形式。1 つの表に `byKind` で分けて入れる）。

- `byKind` 0 … 箱の中身：`dwBoxNo`・`wItemID`・`byCount`
- `byKind` 1 … 今日もらった数：`szAcc`・`dwDay`（日本時間の日付。1970/1/1 から数えた日数）・`byCount`。今日でない日付の行は保存しない（0 個と同じ）
- `byKind` 2 … 記録：`dwTime`・`szAcc`・`szName`・`dwBoxNo`・`byLogKind`（0=入れた・1=もらった）・`wItemID`・`byCount`（古い順）

1 日の数え方は「日本時間（UTC+9）の日付が変わったら 0 個に戻る」で、時刻から日付を `(秒 + 9 時間) / 1 日` で求めます。
データが 1 件も無く、ファイルも無い時は作りません。

箱の行（`swaps`）と使った最大の箱番号は、マップの保存（`aSwap`・`wBoxHigh`）に入ります。
NPC の箱だった頃の行（列名が `dwNpcID`。本番には無く、ステージングの試しだけ）は、箱番号が無い行として読み捨てます。

## 管理者

読むだけです（箱の中身も記録も管理者は変えません）。

- データ API `/api/data/recycle`（MCP は `sbo_recycle`、管理ページ用は `/api/admin/data/recycle`）。詳しくは `docs/ai-data.md` の「リサイクルボックス」。
- 管理ページ（`/admin`）の「リサイクル」タブ：箱（箱番号・マップ・メモ）ごとの中身・今日もらった人・記録（アカウント・キャラ名・品で絞り込み）。
- 箱を置く・直す・消すのは、管理ページ「マップ確認」の「印で変わるマス・宝箱・リサイクル箱」（種類は「リサイクル箱」。マップ上の枠は水色）。
