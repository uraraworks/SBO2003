# 作り手とレシピ（材料から物を作ってもらう）

プレイヤーが町の「作り手」（料理人・鍛冶屋・錬金術師など）に頼んで、材料から物を作ってもらう仕組みです。
プレイヤーがレシピを覚える仕組みはなく、作り手の NPC に頼む形だけです。

## 遊び方

1. 作り手の NPC に話しかけます（向かい合って決定キー、または S キー）。
2. 作ってもらえる物の一覧が開きます。上下で選ぶと、横に「できる物の詳細・必要な材料（持っている数／必要な数）・手数料」が出ます。
3. 決定で「作ってもらいますか？」→「はい」で依頼します。取消（Esc・パッドの取消）で戻る・閉じる。
4. 材料は持ち物のあと預かり所から使われます。できた物は持ち物へ、いっぱいなら預かり所へ届きます（預かり所もいっぱいなら断られ、何も減りません）。
   材料か手数料が足りない時も何も減りません。装備中の物と捨てられない物は材料に使えません。

## NPC に作り手をつなぐ（制御コード）

NPC の台詞を **`@c` + 作り手の番号 2 桁**（例 `@c00`）にします。話しかけた時にも S キーでも、その作り手の画面が開きます。
作り手が無い・停止中の番号なら「返事がないようです」、作れる物が 0 件なら何も開きません。
ほかの制御コード（`@0`〜`@9`・`@a`・`@k`）とは重なりません。

## レシピをつくる

管理ページ（`/admin`）の「レシピ」タブで、作り手（名前・台詞 3 つ）とレシピ（できる物・個数・材料 4 種まで・手数料・並び順）を足す・直す・消します。
アイテムは名前で選べます。保存するとログイン中のプレイヤー全員にすぐ反映され、「AI連携」の変更履歴から元に戻せます。
AI（データ API）からも `maker`・`recipe` として読み書きできます（`docs/ai-data.md`）。

## データの置き場所

`SBODATA/SboDataMakerInfo.dat`・`SboDataRecipeInfo.dat`（ほかの `SboData*.dat` と同じカラム形式）。
サーバーのデータなので公開リポジトリには入れず、ファイルが無ければ「0 件」で起動し、初めて保存した時に作られます。
