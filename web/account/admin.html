管理ページ

サーバーの管理者アカウント（SboSvr.ini の [Administrator]）でログインしてください。

前に使っていたキャラ名からも探せます。

「取得」を押した時点で、ゲームに入っているプレイヤーのキャラ名と今いるマップです（自動では更新されません）。 キャラ名を押すと「キャラを探す」で詳しく見られます。

キャラ名に加えて、アカウント名かパスワードの一部の「どちらか片方だけ」が合った申請です。 当時の様子（レベル・作成日・プレイ時間）やひとことを見て、本人らしければ承認してください。 承認すると、申請した端末でボタンを押すだけでログインできるようになります。

/feedback に届いた投稿です（「管理者だけ」の投稿や、匿名の人のキャラ名も見えます）。 返事は投稿した人に届き、みんなに見せる投稿なら一覧にも出ます。

/changes に出す「何が変わったか」です。プレイヤー向けの言葉で書いてください。 プルリクエストで web/changes/changes.json に足した項目は、デプロイした後に非公開で入ります。 見せてよいものだけ「公開する」を押してください（ここで直した・消した項目はそのままです）。 前の日付のまま公開すると「NEW」は付かないので、新しく見せたい時は「直す」で日付を今日にしてください。

新しく足す

AI（Claude Code など）から、サーバーの設定データ（特技・職業・アイテム・作り手・レシピ・NPC と台詞・マップのイベント／お店／メッセージ・マス目など。 プレイヤーのキャラと預かり所は読むだけ）を読み書きできるようにするキーです。書き込みは必ず「下見（差分を見る）→ 確定」の 2 段階で、確定した変更は下の履歴から元に戻せます。 キーは発行した時に一度だけ表示されます。人に見せないでください。

しおり（お試しの区切り）

お試しで作り変える前にしおりを付けておくと、その後の変更（AI・管理ページ「レシピ」から）を「ここまで戻す」でまとめて元に戻せます。 戻す前に中身を確かめる画面が出ます。追加した NPC は消え、消した NPC は足し直されます。追加した作り手・レシピは削除（空き枠）になります。

変更履歴

マップごとの全体図（屋根を外して、NPC の番号・敵の出る範囲・入口を重ねた絵）と、 そこにいる NPC・敵・お店・イベントの資料（Markdown）を作って、zip で書き出します。 今のサーバーのデータから作るので、データを変えた後に作り直せます。プレイヤーのキャラは入りません。

全部のマップだと、zip は 2 倍で 90MB・等倍で 30MB くらいです（PC で数十秒）。

ゲームの画像（SboGrpData/grp の PNG）を描き直すエディタです。手元のリポジトリの作業フォルダを開いて、 その中の PNG を直接上書きします。サーバーのデータは変わらないので、ゲームに出す時はいつもどおりコミットしてデプロイしてください。

ドット絵エディタを開く

PC の Chrome（または Edge）で使ってください。元のファイルを書き換えない「一時保存」と、 自分のブラウザのゲームだけで絵を差し替えて見る「ゲームで試す」もあります。

マップパーツ（マス目に入る番号）に名前・タグ・使い方のメモを付ける図鑑です。AI が新しい街やダンジョンを考える時の辞書になります （AI からは sbo_parts_dex で引けます）。通れるか・使われた回数・よく隣に来るパーツはデータから自動で出します。 ゲームのデータは変わりません。

組み合わせの見本

「壁で囲った家」「道と草地の境目」のような、パーツを組み合わせたお手本です。AI は sbo_parts_samples で読んで配置の参考にします。 上のパーツの「使われているマップ」から切り取るか、マップと範囲を指定して作れます。

AI（sbo_plan_save）が考えたマップの配置案を、画像で見るページです。ゲームのデータは変わりません。 気に入った案は、パーツ番号を重ねた絵や番号の表を見ながら、管理者ウィンドウで置いてください。

    使っているパーツ

    マップ全体の絵を見て、マスの座標を確かめる画面です。マウスを乗せたマスに枠が出て、座標・パーツ番号・当たり判定・イベントが出ます。 クリック（スマホはタップ）するとそのマスを止めておけます。データは何も変わりません。 水色の枠は扉・入口などのイベントのマスです。

    町の作り手（料理人・鍛冶屋など）に頼んで、材料から物を作ってもらう仕組みを決めます。 NPC の台詞を「@c」と作り手の番号 2 桁（例：@c00）にすると、その NPC に話しかけた時（S キーでも）に作り手の画面が開きます。 材料は持ち物のあと預かり所から使われ、できた物は持ち物へ（いっぱいなら預かり所へ）届きます。 保存するとログイン中のプレイヤー全員にすぐ反映されます（変更は「AI連携」の履歴から元に戻せます）。
